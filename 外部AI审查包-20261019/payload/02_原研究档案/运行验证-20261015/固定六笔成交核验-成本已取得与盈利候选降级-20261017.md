## 3. 为什么13.11回款仍不能当利润

此前已核的固定合并交易 `0x3ca8e82d43f1f34dd92f7a5de60121005ed7ad4cb1b42f6ed094f8a3a1079bb9`，holder两种凭证各减少13.11，实际收到13.11 pUSD。这是真实回款，取得这些份额需要成本。

更早一笔 `0x503c9506df237f3a3cd8a4cc106f8001856766f06b9dac381d504a45c4cece8e`，两种凭证各减少16.88，合并事件已核；其实际pUSD入账仍未取得。为检验最有利情形，先假设16.88全部收回，不把这个假设写成实际到账。

固定窗口总取得A 29.99、B 30.165；两次合并共消耗每种29.99，观察到窗口净变化A 0、B +0.175。这是增量，不是整个钱包最终余额。依既有相同condition/parent/partition的互补凭证关系，单份B最高面额按1计算：

```
假设两次合并按面额完整收回      16.88 + 13.11 = 29.99
假设新增残余B按最高面额收回                       +0.175
合计最有利面额回收                                30.165
减：六笔事件所示本金及holder记载费               −30.50641
条件事件账差额上限                               −0.34141
```

这项计算使用真实取得价格与数量，回收端的16.88到账及0.175最终兑付是明确标出的有利假设。没有扣Gas，没有假造退款/补贴，也没有用未来市场价格估值。若存在未取得的额外返佣或抵销，应由原账证明；因此它只能否定“现有证据已经显示这个闭环赚钱”的说法，不能代替完整实际净损益。

本轮交易也未展示“两个互补结果低于1购入”的折价：前两类单价0.51与0.49相加为1，后两类0.68与0.33相加为1.01。它们发生于不同时间、数量不等，不能把单价加法替代上面的全量事件账，也不能推断当时可同时成交或交易者的真实意图。

## 4. 我们能学什么；目前还不能声称什么
