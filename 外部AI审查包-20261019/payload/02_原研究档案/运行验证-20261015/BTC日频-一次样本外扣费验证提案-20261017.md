# BTC日频：一次样本外扣费验证提案

**决定：只保留一个低成本、可判输赢的独立适配方案，尚不执行。** 小LSTM根据过去价格趋势输出BTC现货0—100%仓位，检验扣除固定假设成本后，是否比买持有、事前风险缩放买持有及固定趋势基准更好。输出是持仓比例，不是价格点预测或盈利概率。

当前已做的新证据工作只有：复读固定作者源码并映射具体函数；以系统Python的stdlib只读既有.venv包METADATA，发现Torch2.8.0、NumPy2.2.6、pandas2.2.2和scipy1.18.1。不导入这些库，不聚合行情、不计算特征/收益、不训练/预测/回测；元数据存在不等于运行健康或预算足够。实际model/effort UNKNOWN，旧FAILED和现金证据不改。

## 1. 为什么值得检验，但不能先说赚钱

固定作者仓库commit **e0352cb0bdbf8045accb1bf1a5705ae0cb9ea624**，MIT许可。Deep Momentum的可借鉴点是“过去收益特征→连续持仓→随后收益→风险收益目标”，不是继续优化绝对价格MSE。经济假说是某些持续趋势可被持仓策略捕获，同时在不利状态降低风险；反转、噪声、换手与成本可使它失效。它不是XTX模型。

已读源码SharpeLoss L32–48、LSTM L502–548、data_prep L90–114、classical_strategies L62–76、107–137。原版方向为可多空、期货风险缩放，训练loss不含成本，后处理还存在从空仓开始时首笔成本遗漏条件。本方案改成BTC单现货、sigmoid长仓/现金、365日、有限历史、显式全成本训练；**是透明改编，不是论文复现，也不是原版已有功能**。论文1990—2020多资产期货历史评估不能移植成BTC成绩。

## 2. 数据与保守时钟

只用已封存dataset1346/v755 CSV，394775342B，SHA256 **c5d5c392b3eeb24d5fc3bcbc4ef78b4e8ce005c84fede7e7fe0fee466c7e67b3**。全文件7780439行静态检查通过，零量1312416行；这不证明每分钟真实成交、当时可得、无延用价或无历史修订。OHLCV没有订单簿挂单量，不能解释或修复旧订单簿LSTM的35倍MSE失败。

未来预检只接受UTC标签00:00—23:59恰1440条唯一分钟、基本QC有效的完整日，不补/删/修。零量保留、计数披露，不按收益或量大小剔日。2012首日及2026最后部分日按完整性排除；计划期若缺必要日即技术无效，不临时换期。

日价格C_D为标签23:59的Close；不以全天VWAP或未来成交量选仓。执行日e的决定仅看 **D=e−2** 及之前：60个特征日D−59…D，原价需求e−313…e−2，共312个原价日标签，最早原价距决策日313天。于e **00:10UTC** 以该分钟Close作为执行代理，持有到下一日同标签；该值不是可成交报价。超过24小时的滞后缓冲分钟开收端歧义，但仍需明确假设：数据在相关最后标签后24小时10分内可得。**精确开/收端、历史发布时间和最终修订仍UNKNOWN**，不能把保守假设写成已证事实。

固定零量处置：当日信号先确定，不用当日参考柱Volume决定信号。若00:10参考柱Volume=0，不假设能按延用Close成交：BTC数量/现金不动、费用0；保留日期和盯市损益，不向未来寻找有利价格/正量柱，下次仅在下一预定日处理新信号。正量也只是有交易的有限证据，不证明本人的成交、容量或Close价格可得；该历史no-fill规则不是已验证实盘订单机制。终点零量且仍持BTC，不能虚构平仓和已实现末现金，该段执行证据无效、整体不得PASS。记录全部零量代理次数、未成交/漂移与剩余权益；成本压力不能消除无成交证据。

## 3. 一次冻结的模型与分割

| 用途 | 首个执行日 | 最后平仓日00:10 |
|---|---|---|
| 训练 | 2014-01-01 | 2018-12-31 |
| 隔离，不拟合/计分 | 2019全年 | — |
| 验证 | 2020-01-01 | 2021-12-31 |
| 隔离，不拟合/计分 | 2022全年 | — |
| 最终测试 | 2023-01-01 | 2025-12-31 |

每段最后日期只平仓，不开新仓跨出边界。两段全年隔离大于最早原价313天偏移；隔离年可供后续窗口历史，但不能拟合标准化或参与训练。验证后不重训；不random fold。本项目已有多次尝试，这只是本次评估前冻结，不是历史发生前预注册；历史heldout也不是未来实盘。

只用五种特征：过去 **1/21/63/126/252日** 简单收益，除以截至该特征日的60日收益总体标准差与sqrt(h)。波动分母下限1e−6。没有MACD、成交量、日历或新特征搜索。均值/总体标准差仅用合格TRAIN窗口所含**唯一特征日期行**拟合；常量列置0，标准化后固定截到±10；不修原价格。不对收益目标做缩放。

PyTorch单层LSTM(5→16，60步，bias，dropout0，非双向、无projection)，取最后步接Linear16→1再sigmoid。每个窗口隐状态从0开始。输出s乘事前风险上限：
**v=min(1,0.40/[sqrt(365)×max(σ_(e−2),1e−6)])，w=s×v**。
w是扣交易成本后的BTC资产比例，余为美元现金；不借贷、不做空、无杠杆。40%是本次固定研究风险目标，不是保证实际年波动≤40%。

单seed **20261017**，sorted named parameters全部显式CPU uniform[−0.1,0.1]，不另设forget bias；透明区别于原Keras。float32网络、float64标准化与现金账。Adam lr.001、betas(.9,.999)、eps1e−8、weight_decay0、amsgradFalse，梯度L2裁剪1。固定 **100 epochs**；每epoch全训练期一个loss/backward/update，窗口可按64块计算但不detach，不shuffle。不早停、不挑最好epoch、不调参/换seed；只用epoch100。

训练目标为精确下述25bps现金账的日净收益Sharpe负值，sqrt365×mean(q)/sqrt(populationvar(q)+1e−8)。验证不用于挑权重。保存全部100轮loss、收益均值/标准差、梯度norm和有限性日志，避免再次缺训练轨迹却猜收敛原因。

## 4. 把成本和仓位漂移写清

每段从**5000USD现金、BTC0**起步，现金利息0；使用连续BTC单位，是虚拟研究账，不冒个人实际最小订单、取整或交易资格。

主口径单边 **25bps**，压力口径 **50bps**，均按绝对参考美元成交额收取，作为手续费+价差/滑点的合并假设。例如25bps可理解20+5bps的研究拆分，**非本人实测费率**，不可又重复加一遍。两口径使用同一封存意图信号/目标权重，不重训；各自独立核现金、BTC数量及no-fill后的实际漂移，不声称持币数量相同。压力口径改变现金路径，不改变模型意图。

令P为执行代理、V⁻为交易前净资产、a为漂移后BTC权重、w为目标**交易后**权重、c=bps/10000：
- a=原BTC数量×P/V⁻；s=sign(w−a)，相等时s=0。
- **φ=(1+c·s·a)/(1+c·s·w)，V⁺=φV⁻**。
- 新BTC数量=wV⁺/P，现金=(1−w)V⁺。
- 交易参考额N=|新数量−原数量|P，费用=cN；验证V⁻−V⁺=费用及现金守恒。
- 漂移a来自前仓和实际代理价格变化，**不是直接用|w−w_prev|代替换手**。
- 每个持有区间q=φ×[1+w(P_next/P−1)]−1；最终平仓再乘(1−c·a_terminal)，并折入最后区间一次。首笔从空仓开仓也支付，末笔不得漏掉或重复扣。
- 在w=a处费用0，训练采用零成本次梯度；其余用同一分段自融资公式参与梯度。零量no-fill日有效w=a，原目标不执行；因为漂移，实际仓位可能偏离目标风险上限，必须记录，不能假称始终符合目标40%。模型训练和全部基准/评分均使用这个同一规则。成本进loss是本次适配，原代码没有。

不采用测试期实际波动率事后缩放。个人税、真实交易所/渠道、离散最小单位、提现保管、市场冲击、实际流动性和地区可用性未核；不能把假设扣费账当实盘全费利润，也不因这些未知否认已核历史现金。未借贷所以没有借款融资费，现金利息0是显式假设。

## 5. 强基准、输出和判输赢

全模型/基准共用日期、价格代理、首末收费和两档成本：
1. BTC全仓买持有；
2. 风险缩放买持有w=v；
3. 固定63日趋势：C_(e−2)>C_(e−65)时w=v，否则0；
4. 现金0仓、利息0。
基准不调参，不是额外候选模型。主增量比较是具有相同事前风险上限的第2/3项，实际实现风险仍可能不同。原始全仓买持有完整报告，作为机会成本/beta参照，不把风险预算不同下绝对收益更低自动判成无AI优势；也不做测试后等波动缩放。

只在一次完整训练后封存checkpoint/scaler/settings及全TRAIN/VALIDATION/TEST目标仓位，再封存各模型/基准的两档完整虚拟成交现金账，最后统一评分。账列包括决策/特征截止/价格代理时点、信号/风险上限/目标与漂移权重、交易前后BTC/现金/权益、交易量、假设费及终点平仓标记。不得看测试输出后择优。

全部区段、基准、成本、年份均报告：净权益/净额/总回报/CAGR、年化波动/Sharpe、最大回撤、换手、费用总额、平均敞口。Sharpe按日净收益总体标准差和sqrt365计算；现金全零约定0，其他零标准差不能冒有效通过。回撤是固定日估值/交易点口径，**不是日内最大回撤**；首末费用计入同一权益路径，具体公式封存在protocol.json。**一次候选通过须同时满足**：
- 验证25bps末权益>5000；
- 测试25bps末权益>5000、Sharpe至少高于风险缩放买持有和固定趋势两基准最大值 **0.20**、最大回撤≤35%；
- 对这两个主基准分别比较测试每日净log收益差：均值>0，固定90日圆形区块bootstrap、10000次、seed20261017，单侧 **97.5%**均值下界>0（2比较Bonferroni总α.05）；
- 测试50bps仍正净额、末权益高于同成本两个主基准且最大回撤≤40%。

这些是本次候选筛选阈值，不是所有赚钱策略的必要条件，不以MSE或财富1%代替收益验收。三年单资产的区块统计依赖平稳/相关性假设，不能证明稳定alpha。全部完成但任一门槛未过＝本固定适配NOT_SUPPORTED，不概括所有方向无效；身份/时序/数值/现金恒等有错＝技术无效；资源超限＝资源停止，不伪装市场失败。均不得自动改日期/成本/参数重跑。
