## 预测怎样才可能变成钱

以下仅为教学代数，不是XTX交易或新收益回测：主动买入一单位、随后主动卖出，若价格分别为卖一价A0、买一价B1，额外成本为C，则净差额为B1−A0−C。用中间价M和价差S表示，同式为：

`中间价变化 − (入场价差＋出场价差)/2 − 额外成本`

C不再重复计入报价已经包含的价差。报价不保证实际可得。[Investor.gov订单说明](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)解释了买卖市价单通常分别接近卖价、买价执行。这里只引用一般执行概念，不将股票监管或API规则套给Hyperliquid

因此只看对方向不够，还需幅度、可成交价格与费用；被动挂单另需排队和实际成交证据。数据授权与代码可读均未补齐这条盈利链，也没有资金容量结论。
