# 事前规则与后续净盈利案例：Carver 的可复用环节及证据边界

读取日期：2026-10-16（北京时间）。本轮只做公开资料读取、固定版本源码审阅、已公开记录的静态比对及算术检查；未运行模型、策略、回测、交易或账户接口，未新增付费、依赖、注册或对外留言。

## 1. 结论先行

本轮最值得深化的候选是 **Rob Carver 的 pysystemtrade 系统**：有早于后续市场结果的开源规则、有多年自报实盘表现、还持续公开持仓对账和成本诊断。它比仅给出漂亮回测或胜率的案例更接近要求。

但 **尚未找到本轮全部条件都通过的案例**。Carver 的年度净盈利仍是作者自报；公开文件不是该年度完整的账户权益、资金进出、所有成交及逐笔费用原账，不能独立重建净收益。当前开源版本、历史版本、公开配置与实际运行报告也未完全绑定。将它列为“有后续实盘净盈利自述、可复用代码的研究样本”，不列为已经核实可复制赚钱的正例。

最值得低成本借鉴的一个环节是 **用慢速趋势形成经过波动率归一化的方向信号**。这是一项具体、公开、可以理解的统计规则。它是否在某个个人账户中扣费后有效，仍需另一组独立证据；本轮没有启动该验证，也不跳到新的交易试验。

## 3. 作者披露的利润与费用：有正数，但尚未独立闭账

以下均是作者公开年度自述，**不是本轮复算确认的收益率**：

| 项目 | 2025/26税年 | 上一税年 |
|---|---:|---:|
| 期货账户综合净表现 | +23.7% | −16.3% |
| 单列佣金 | −0.33% | −0.29% |
| 单列滑点 | −0.55% | −0.56% |
| 其他列示费用 | −0.04% | −0.05% |

2025/26的净数还包括现金相关利息、汇率及现金类ETF影响；不能将23.7%全部归因于趋势信号，也不能将作者总资产组合表现与期货账户表现混用。金额/百分比基数和完整现金流未经原账重建，不能外推个人资金容量、未来年化收益或复制后的收入。

费用有三个容易误读的点：

1. 年度已称“net”的数字，不应再机械扣一遍配置费率；必须先核它已包含哪些实际扣款。
2. `Costs_report`的both面板包括commission与spread；三个面板不能相加。它们主要是预期单笔成本及风险调整单位，不是实际年度现金支出。
3. 实际成交价已反映当时买卖价差/滑点效果，按成交价算出的损益再完整扣一遍滑点，会有重复计量风险。年度作者披露的计算链尚未取得，不能断定它已重复扣费或漏扣佣金。

作者披露执行算法相对另一种成交假设可减少成本，这属于反事实执行估计；不能把节省估计当作额外到账利润。本轮不采用该数字证明预测优势。

## 4. 它凭什么赚钱，钱从哪里来

### 已公开的机制

在已取得的核心函数 `ewmac(price, vol, Lfast, Lslow)` 中，指数加权移动平均线（近期价格权重更高的平均线）的快线减慢线，再除以日价格变动的波动率：

`原始方向信号 =（快均线 − 慢均线）÷ 日价格变动波动率`

这是未缩放、未封顶的原始信号。完整系统还要结合多个规则、权重、资金和风险约束，才能形成实际合约数量；不能把这几行函数当作整个赚钱系统。当前公开配置还含carry等其他规则，作者2026年度文章认为该年慢速趋势表现较好，但未证明单个EWMAC规则解释了全部实盘利润。

```mermaid
flowchart LR
    A[合法取得的历史行情] --> B[判断近期方向并按波动率归一化]
    B --> C[组合与仓位约束]
    C --> D[实际成交和持续对账]
    D --> E[后续价格变化形成持仓损益]
    E --> F[加减利息和汇率等影响 并核对费用]
```

他用自己的账户持仓，不需要先找到银行或基金客户为预测买单。若持有多头后价格继续上涨，或持有空头后继续下跌，就可能获得方向性差价；反向变化则亏损。期货盈亏经结算体系在相反头寸间实现，不意味着我们已识别具体哪家机构付了哪笔盈利。其现金利息等另有来源，不能全部叫交易对手亏损。

### 为什么可能存在优势：推断与未证实处

**行业解释/待检验假设**：市场参与者逐步调整仓位、反应速度和约束不同，可能使价格趋势延续；趋势规则试图在长行情中获利，并承担反复反转造成的损失。公开研究 [AQR, 2017-10-31](https://www.aqr.com/insights/research/journal-article/a-century-of-evidence-on-trend-following-investing) 提供历史时序动量背景；它不是Carver账户原账，也不证明我们今天有可交易优势。

风险控制、分散和减少无必要换手，可以改善一项已有优势的实现；它们本身不能凭空产生正的预测收益。反转频繁、行情突变、合约换月或执行不利时，损失与费用可以超过顺趋势收益。上一年度负表现需要和盈利年一起保留。

这个机制与XTX为客户报价做市的现金流不同。我们可以借鉴数据、信号、风险和执行的研究顺序，不能说已复刻XTX的私人预测模型。

## 6. 我们能低成本复制哪个环节

本轮仅选一个：**慢速趋势的原始信号生成**，即快慢均线差除以价格变动波动率。代码可以阅读，不需要训练大模型或购买GPU。它回答“市场近期方向与波动相比有多强”，不是精准预测明日价位。

| 可借鉴内容 | 仍缺少的东西 | 缺少的后果 |
|---|---|---|
| 固定公式、固定版本，完整记录当时输入和信号 | 合法、连续、当时可见的数据版本；期货还需合约与换月口径 | 信号可能使用错误时间、错误波动率或不真实连续价格 |
| 只保留这个信号环节作为候选 | 同一固定规则在独立未来数据上的扣费证据 | 无法确定它对我们是否赚钱 |
| 读取作者成本与对账设计 | 自己可实现的成交价、佣金、滑点、资金/借贷条件 | 纸面方向正确仍可能净亏 |
| 理解其在组合中的作用 | 与作者相当的分散、合约颗粒度和运行维护能力 | 少数头寸承担更大集中风险，不能承接作者账户收益 |

免费开源的范围是软件学习与许可内复用。行情、维护、交易、税费和资金风险并不因代码免费而归零。本轮未核定一套适合个人的具体新数据授权或精确运行费用，不承诺0成本交易。改成少数股票/ETF、只做多或其他市场，会形成新的策略，不能继承该账户的历史成绩。

**研究判断**：值得保留作机制与工程研究；还不足以登记为“已有完整证据的赚钱方案”，更不足以据此开发或交易。下一项若继续针对本例，只需解决一个核心证据任务：同一固定运行版本能否对上一个连续年度的完整权益/资金流、持仓、成交和实付费用。当前公开诊断文件未完成这件事；不发新求证、不等待某个作者回复作为其他研究的前提。
