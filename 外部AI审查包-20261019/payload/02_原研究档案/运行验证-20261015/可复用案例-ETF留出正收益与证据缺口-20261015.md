# 可复用案例核验：ETF 留出测试的正收益与证据缺口

读取日期：2026-10-15。范围：公开资料研究、冻结源码阅读、发布包完整性核验、保存成交账目对账。没有运行模型、导入项目代码、重跑回测、产生新策略路径、连接账户或交易。此前 RSI 与 Funding Harvester 样本原件和报告保留。

## 1. 结论先行

本轮最有价值的新候选是 Stefan Jansen《Machine Learning for Trading》公开项目的 ETF 跨资产配置案例。与只有收益图片的项目相比，它提供了更完整、可核账的原件：预测、目标权重、模拟成交、交易损益、每日权益、账户状态以及训练和交易参数。

**已确认的是：发布包内一个标为 holdout（留出测试）的模拟账户，在 2024—2025 年按包内佣金和滑点假设后，保存收益为 +18.1409%，账目能够闭合。未确认的是：这段历史是否始终未被用于改选模型，以及模型是否优于匹配风险和成本的简单持有。行情的完整个人自动化复用授权也未闭合。**

因此，这个候选比前两个样本更适合拆解和核账，尚不能登记为“公开数据、个人复用授权、严格独立样本外盈利证据全部通过”的案例。这里明确保留未完成项，不把档案齐全写成已经找到可复制的赚钱优势。

公开入口：[项目](https://github.com/stefan-jansen/machine-learning-for-trading)、[2026-09-20 复制包发布](https://github.com/stefan-jansen/machine-learning-for-trading/releases/tag/v3.1.0-artifacts)

## 3. 它具体怎么做，钱来自哪里

针对这条 OLS/5 日预测链，已核对的过程是：

历史每日价格、成交量等资料  
→ 计算 71 个输入特征  
→ 用 OLS（普通最小二乘线性回归，将多个输入按拟合权重合成评分）预测未来 5 个交易日收益  
→ 在约 100 只跨资产 ETF 中挑评分前 10 名  
→ 用 HRP（层次风险平价，按历史波动及资产间关联分配权重）配置资金  
→ 每周五收盘形成目标，按下一交易日开盘规则模拟成交  
→ 配合 6% 跟踪止损及仓位、现金限制  
→ 按设定的每股佣金和买卖价差扣费。

实际资金配置不是“前 10 名一律各 10%”：先按评分选资产，再由 HRP 分配权重。71 个特征包括多期涨跌幅、波动、相对强弱、趋势、资产间排名、市场状态和条件波动等；其中部分特征自身依赖时序模型。不能把此例说成只需过去 5 天价格，或只复制一行线性回归即可。

训练原件记载 2006-01-03—2023-11-29 为训练期，预测期为 2024—2025；模型重新拟合，预测文件与交易文件有注册身份对应。未因本次查证训练或运行它。

来源：[原始运行源版本的 holdout 代码](https://github.com/stefan-jansen/machine-learning-for-trading/blob/19b5193c6c7faaf3596b100234725d555ab20c86/case_studies/etfs/19_holdout_backtest.py)、[发布锁源版本保存输出](https://github.com/stefan-jansen/machine-learning-for-trading/blob/73f066b4d225fe5419d1bc67bec7bf24c7e0fec7/case_studies/etfs/19_holdout_backtest.ipynb)。精确模型和输入定义见本地原件 selected/training/5ff0fa98f34e/spec.json。

**从第一性原理看，它的直接收入是持有资产后的价值变化；没有客户付服务费，也没有卖方无条件支付预测奖金。** 模型若有额外价值，应表现为：在承担相近风险、使用相近资金和成本时，选到的组合比简单持有更好。这一条尚未由本次原件闭合。

以下三层必须分开：

| 层次 | 当前证据 |
|---|---|
| 选择机制 | 公开模型和交易参数可以解释“选了什么、怎样配置” |
| 盈利账目 | 按保存模拟价格和成本，账户为正；内部账目已对上 |
| 独立优势 | 尚未证明正收益来自模型，而非市场上涨、利息暴露、组合构建或版本选择 |

具体线索：保存损益中 BIL 贡献 5,066.1069 美元，约占总净利润 27.9%。BIL 是追踪美国 1—3 月期国债市场的 ETF，[原始招募说明书](https://www.sec.gov/Archives/edgar/data/1064642/000119312524245930/d837416d497k.htm)可确认其目标。**这说明需要把短债收益暴露与预测优势分开；该比例本身不是经过控制变量后的收益归因。** 尚未证明“持有 BIL 就能复制该账户”，也未把其余约 72% 都归为模型优势。

可能的预测优势假说，是跨资产趋势、风险状态和相对排名对随后收益有一定信息；这是待检验解释，不能由正账户收益倒推出已成立。此例也没有证据可以视为 XTX 的私人模型或赚钱机制复现。

## 4. 为什么暂时不能称严格独立的样本外成功

发现了一个会改变结论的版本问题：

- 发布包 SOURCE_COMMIT 是 73f066b4…；实际保存训练和交易记录指向 19b5193c…。
- 冻结的 19_holdout_backtest.ipynb 输出，与这次核到的 OLS/5 日/周度/HRP/+18.14% 原件一致。
- 可是同一冻结树的 README 讲的是另一条 GBM/21 日/月度链，并声称该链于 2026-08-31 已查看相同 2024—2025 测试窗。
- README 的旧链身份在当前包注册表找不到对应行。不能把该 README 针对 GBM 的基准比较、统计显著性或搜索调整结果拼接到 OLS。

本次进一步核到：原始运行源的选择器只从 validation 结果中选优；现存验证期排名第一确为 OLS，其登记早于本链 holdout。当期选择机制有依据，不能无证据指责作弊。

但“代码只读验证期”和“研究者历史上从未参考过测试期”是两件事。现存 decision_artifacts、candidate_sets、artifact_supersessions 为空，没有完整不可变的事前选择记录或旧链退役映射。故：

**未证明跨版本从未看过测试窗；也未证明确实根据测试结果后验改选。严格独立性为 UNKNOWN。**

详细证据：版本与选择链复核（未随包收录；原相对路径：`运行验证-20261015/evidence/reusable-case-20261015/jansen-etf-audit/lineage-check.md`）。

## 6. 你能复制的环节和不能直接复制的结果

最值得借鉴的一个环节是：**将跨资产预测评分转成有固定频率、明确权重和完整费用账的组合决策。**

| 可复用环节 | 可借鉴内容 | 少了会怎样 |
|---|---|---|
| 模型与输入定义 | MIT 代码、71 项输入名称、5 日目标、训练截止、预处理和模型身份 | 换输入或目标后已不是同一案例，不能承接它的收益 |
| 选择与配置规则 | 前 10 名、周频、HRP、风险约束的固定连接 | 只复制预测器无法复制组合收益；事后挑规则会放大偏差 |
| 研究和核账流程 | 输入哈希、冻结预测、每笔成交/费用、每日权益、明确验证/测试身份 | 正负收益无法追溯，也难发现费用、版本和时点错误 |

判断：线性评分器本身不需要聊天大模型或大型 GPU 集群，个人可以研究这些公开组件；完整特征工程、输入复原和评估仍有工作量。这里没有实测本机总耗时，也不把作者机器的运行时间当成本人的承诺。

不能直接复制的包括：一条已证明的额外收益、原始数据许可、未来成交条件，以及资金放大能力。若把 100,000 美元账户按比例改成 5,000 美元，整数股、最低票费、100 美元最小成交额和 0.5% 最小权重变动规则都会改变操作，不能把 +18.14% 原样缩放。

当前只值得保留为**较强的公开研究候选**。若以后推进评估，首先要固定同一条版本和合法可用的输入，再审其相对匹配风险基准的增量；缺这些证据前，不把“另跑出一次正回测”设为成功条件。本轮没有执行该下一阶段。
