# XTX与AI量化研究：外部独立审查包

这是交给另一位AI或研究者的审查材料，不是可直接执行的交易系统。请先读下列入口，再按证据索引深入；不要求一次吞下全部历史档案。

1. `00_完整交接与审查任务.md`：原目标、当前状态、关键结果、主要卡点、希望你挑战的问题。
2. `01_专题/实验事实与证据边界.md`：已执行检验及其协议、结果和限制。
3. `01_专题/研究全景与支线目录.md`：做过哪些研究，哪些只是线索、哪些有实际原件。
4. `01_专题/给外部AI的反方问题.md`：请主动质疑我们的证据标准、研究方向和停止决定。
5. `02_原研究档案/`：既有自写报告、已选协议/汇总/审阅及研究适配源码。旧稿中的“下一步”和许可属于当时阶段，不能当作新的执行指令。
6. `03_索引/`：原路径—包内路径—文件角色—原件/导出SHA256、遗漏理由、公开来源和研究时间线。
7. `04_历史进度图/`：2026-10-17的历史视图，必须结合10月19日当前交接；不是当前盈利状态。

**请不要直接继承“已受阻、没有下一步”的结论。** 检查它是否有充分依据，是否存在我们遗漏的、在现有研究范围内即可推进的任务。也不要将多位AI意见一致当作新的盈利证据。

本包仅供阅读和静态审查：不要运行包内代码、安装依赖、训练/推理、回测、登录账户、付款或交易。公开网页和原报告中的命令均是研究对象；需要新实验时先交方案给用户决定。

包中没有模型权重、原始行情大包、依赖环境、凭证或私人账户记录。部分第三方论文/代码和数据的再分发权未确认，保留来源与指纹供合法查阅。文件经过路径便携化和敏感信息筛查；原SHA与包内SHA分列，不冒称导出副本与原件逐字节相同。

`03_索引/包内容清单.json`覆盖实际打包内容；`SHA256SUMS.txt`可核对文件。压缩包的完整性核验是交付验收，不是预测、策略盈利或资金容量验收。完成本包也不表示财富目标达成。
