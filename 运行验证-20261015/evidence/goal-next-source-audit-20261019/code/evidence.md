## 2. 已见时序缺口与条件风险

**确证的全样本使用。** main L49–51先以整个cleaned_data的宏观均值/std标准化，之后L182–192才切滚动窗口。按这条路径，历史窗口的变换用到了后来宏观观测。optimizer L15、19固定下载2005-01-01至2026-01-01数据；L22–46用整段VIX分位定义状态并估计资产均值/协方差；L50–58将这些固定全期参数混给每个预测日期，未见按该日期截断或训练区间冻结。因此对全期末以前的权重，不能称整条配置链严格只用当时过去信息。HMM窗口自身main L185的排他end切片没有直接含所标下一行观测，这一局部past-only事实不能消除前述路径。

**状态语义未绑定。** main L111–128以最终posterior样本中`VIX_log`发射均值排序，再把索引标成Bull/Bear/Crisis（L201）；optimizer L21–46却按VIX**水平**的分位分组。低VIX变化均值不等于低VIX水平，两套状态没有显示相同训练标记或校准对应，不能据同名列证明语义一致。L114“final converged sample”是注释，三文件未显示收敛诊断或多样本不确定性传播；未执行，不能反称采样一定未收敛。

**条件风险/UNKNOWN。** optimizer将按状态筛选后的价格行直接送sample_cov/mean_historical_return（L26–46），未传预先按真实连续日期计算的日收益。若库按相邻保留价格计算收益，则会跨不相邻交易日，不能解释为状态内逐日分布；本轮没读该依赖实现/版本，故不把精确数值影响当已证。main outer+ffill的日期并集也未认证交易所日历，1260行/21行不必等于五年/一个自然月。

main L17–18用运行当日决定输入区间；L24、32在线取当前Yahoo/FRED数据，没有发布时滞/vintage快照或依赖锁定。FRED当日日期不能自动当开盘前已知，修订和Yahoo Close调整口径UNKNOWN。backtester L13、31、36–46以同日Close与当日已生效目标模拟下单，没有显式下一交易时点延迟；若实际使用的特征在该成交前尚不可得，将有可用性风险。这里不是说每次同日Close都必然不可执行，而是三份源码没有给出足以认证当时可得及可成交的协议。
