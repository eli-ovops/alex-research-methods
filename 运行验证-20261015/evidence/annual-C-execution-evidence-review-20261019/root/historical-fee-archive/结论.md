# 公开来源补证：数量单位有依据，历史费率未取得当日正文

读取日期：2026-10-19。纯公开来源研究；没有访问私有行情或QC报告，没有新的模型、金融核算、数据下载、账户或交易。这里的“数据下载”指行情对象；本轮保存了公开网页/档案索引原件。

## 可更新的判断

**Bitstamp/BTCUSD quotes中的ask_amount、bid_amount按BTC解释，已有交易所专属文本支持。** Tardis字段定义明确继承原交易所最优价位数量；Bitstamp自己的订单簿说明则明确按价格列出比特币数量，另篇区分BTC数量、每BTC的美元价格与订单美元价值。[TradeView说明](https://blog.bitstamp.net/post/new-trading-interface-tradeview/)、[Understanding Tradeview](https://www.bitstamp.net/en-gb/learn/crypto-trading/understanding-tradeview/)。

这是**跨来源绑定推断**，强于只有BTCUSD/spot标签的行业惯例；仍不是2022转换器或私有目标对象的逐字段验证。两篇当前页面分别标2014/2024发布日期，带现代品牌/页脚，不能当相应年度冻结快照。Root直接读取了Owner保存的两页原生返回相关完整段，未只依赖其结论。

|字段|本轮可采用的解释|证据等级/限制|
|---|---|---|
|ask_amount / bid_amount|最优价位的BTC显示挂单数量|供应商定义＋交易所资料的连接推断；不代表成交保证或全部深度|
|ask_price / bid_price|每BTC的USD报价|同上；未读取目标值|
|timestamp|交易所给出的时间；缺失时可回填local_timestamp|供应商明确定义；不一定是独立撮合时钟|
|local_timestamp|采集端消息到达时间|供应商明确定义；不是用户策略当时的接收回执|

两时钟均按UTC epoch微秒定义。这是旧文档复核，不冒称本轮新发现；也不解决原OHLC柱标签开闭端、输入首次可用或用户延迟。[Tardis字段定义](https://docs.tardis.dev/downloadable-csv-files/data-types.md)。具体来源与覆盖见[单位来源报告](../../review/quote-unit-source/结论.md)。

## 历史费率的存档尝试没有补成正文证据

1. 正常只读Wayback CDX，查询同一`www.bitstamp.net/fee-schedule/`在2021-12-31至2022-01-02的HTTP200捕获，返回空索引。此有限查询不证明无历史版本。
2. 有界扩展到2021-10-01至2022-03-31，按digest折叠、上限30条，返回20211016093118这一个内容摘要。折叠结果不能当完整捕获时间表。
3. 一次正常GET该[2021-10-16捕获对象](https://web.archive.org/web/20211016093118id_/https://www.bitstamp.net/fee-schedule/)，HTTP200、Memento日期匹配；实际正文只有212字节，包含防护脚本，无费率正文。其SHA1与CDX摘要相同，说明存档本身就是该防护页，不能用存档时间或200状态确认费率。没有执行脚本、更换回放修饰符或再次取该资源。

因此，不把它计作“已取得2022年当时费率”。已有2019公告及标2021日期的现存官方文章对0.50%历史候选的支持保留；2022-01-01精确有效版与具体账户/实体适用仍未核。没有把当前0.30%/0.40%、后来的零费或50bp压力假设回填为真实历史全费。

## 对继续研究的判断

这轮减少了单位解释的未知，没有新增盈利、成交或资金容量证据。市场文件已本机存档，QC报告也已在本机生成，但真实内容结论没有传回AI，仍不能据过程状态宣布数据合格。

**该支线应停止重复查同一接口、目录、当前费率及同一失效存档。** 更多同类资料或单日报价核查都不能产生独立时期的净盈利优势证据。当前保留年度配置的受限历史候选；不把来源定义通过当成值得投入或放大资金的理由。

财富目标的关键缺口仍是：一项个人可捕获、可及时执行、完整成本后在独立时期成立的优势，以及放大资金后仍成立的证据。已完成C单元不授权新的账户/模型/费用核算。本轮未识别出能立即补齐这些缺口的未读具体原件，也没有已批准未完成的金融执行单元；这不是证明外界不存在机会，不应再用状态报告替代新证据。
