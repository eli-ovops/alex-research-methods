# C对照之后：先核执行证据，不重复泛搜

读取日期：2026-10-19。范围：既有原件静态复核、两份官方公开网页的中介文本读取。没有新增模型、训练、策略路径、回测、账户连接、付款或交易；C实验结果保持封存。

## 决定

**保留年度动态配置为历史候选；不提升为已证赚钱方法，不进入资金放大。** C对照是上一单元的实质进展；本轮没有取得新的盈利或实际成交证据。当前应补的是与这条规则对应的执行原件，不能把重复刷新接口、改变成交量分母或再写一份状态报告当作解决卡点。

2020—2025、初始5000美元、单边25bp假设下，已封存A/C/B期末虚拟现金分别为55,144.15 / 50,938.72 / 49,274.54美元，最大回撤分别56.23% / 65.18% / 74.34%。50bp下A仍在终值和回撤上优于C。它回答“普通固定比例年度再平衡是否解释全部A/B差额”，不回答未来优势或现实成交。C结论及旧A/B门槛不改。

## 本轮排除了什么错误的下一步

- **旧13事件表不是新C结果的执行认证。** 它锚定2014起点账户；最新C问题是2020起点，后续目标、数量和资金路径不同。固定一小时成交量表有描述价值，但没有可执行对侧深度、延迟、部分成交或冲击字段。
- **来源目录不是目标盘口。** 现有Tardis目录声明2019年后有Bitstamp档案，月首免费可能覆盖元旦；它没有证明目标日完整、所有日期免费或当前处理方式获准。该路线与使用范围此前已研究，不能算本轮新发现。
- **公共API入口不是免费完整历史承诺。** 当前文档列有公共`order_data`、`since_id`和`until_id`，默认前24小时；默认值不是最大保留期。本轮没有调用它，也没有证明它能回溯2020。
- **资料已存在与字段尚未获得分开。** 原395MB OHLCV文件可读，不是丢失；它仍没有目标时点对侧盘口。Unix秒/UTC网格有依据，原CSV柱标签开闭端、Close首次可用及修订时点仍未绑定。

## 本轮刷新费用后的实质限制

读取[Bitstamp官方费率页](https://www.bitstamp.net/fee-schedule/)，中介抽取保存于`02-fees.source.txt`及同名receipt。普通现货最低成交额档页面列maker 0.30%、taker 0.40%；实体、渠道及用户实际适用性未核。maker指挂单被后来订单成交，taker指立即消耗现有挂单，不能任意选择低费率。

- 原25bp综合摩擦假设低于上述当前最低档单项交易费，不能称为当前小额账户的已核全成本。
- 原50bp仅是压力假设，不等于已证明价差、滑点、延迟与其他费用都被覆盖。
- 页面另列Basic Trading的固定价差和可变价差。这是另一交易渠道，不能直接叠加至订单簿费率，或回填历史账。
- 最低订单、闲置账户、充提费用均有具体币对、实体或行为条件；本轮没有取得用户实际适用证据。闲置定义包括登录行为，不能因每年交易一次就自动扣其费用。

这是2026-10-19取得的网页内容，**不是2020—2025完整费率历史**。页面银行汇率区的“Last updated”也不是整张费率表的统一生效日。读取为Jina中介文本，不冒称直接交易所HTTP原件、账户报价或逐列视觉验收；部分表头被展平的列不作延伸解释。

## 唯一相邻问题：2022年两条既定卖单是否有显示盘口支持

共同2020首配买入`0.5474803783461116 BTC`适合检查起步条件，却不能解释A/C差额。为贴近比较问题，本轮进一步只读了两份已封存25bp账的第733行，定位`2022-01-01 00:10 UTC`标签、Close代理`46376.22 USD`：

|原账字段|A动态年度目标|C固定比例年度重配|
|---|---:|---:|
|原定BTC目标比例|0.6448105044976772|0.7853985165876642|
|原账卖出BTC数量|0.025082228728719846|0.03713011298370417|
|原账参考交易金额USD|1163.218957613432|1721.954288357121|

上述是已存在账行的抄录，没有重新计算交易。两账户继承了不同的此前财富与持仓：不能把卖出数量差直接归因于这一年的权重选择，不能据此认为A一定多卖或每次都更省成本。此事件比共同首配更能区分实施条件，尚无证据说它是全程最坏容量或最有统计判别力的事件；选择它已经看过历史，不能把后续核查称为盲测策略表现。

待补证问题：**在先证明该输入可用的时点、订单类型和固定执行时限后，同所BTC/USD买盘的价格档与数量，是否分别为这两笔卖单提供预定全成本约束内的显示盘口支持？** 两者应作为替代账户分别核，不假设两单同时入场。需要可信初始盘口、必要更新与缺口记录、双时钟及单位说明、当时适用费用；单有BBO或当小时成交量不够。

取得这些资料后仍须区分：显示盘口支持、延迟后的可成交反事实、本人实际成交回执。第一层通过不等于后两层，更不认证六年全部调仓或更大资金。这里是待解问题的定义，**不是已冻结执行实验或新的计算许可**。

之前已有Bitstamp来源求证草稿，尚未发送；本轮没有新建外部消息。若需要联系供应商，须另取得具体发送授权。未取得澄清不等于供应商禁止全部个人研究，也不意味着该路线必须永久等待它回复。

## 更大的卡点仍在

即便一笔执行核查通过，也只补一个执行条件。2020—2025已被研究，新增独立市场样本仍为0；A/C风险路径不同，年度实际分化次数有限。7天或15天没有非零调仓时，两条同起点路径可能按定义一致，不能快速认证年度规则的相对优势。

因此，当前能复制的是仓位规则与可复核记账；尚未证实的是独立时期的成本后优势、真实执行和规模扩大后的存活。它没有复刻XTX的客户流、报价/库存/对冲体系或企业所有权，也未提供达到Gerko财富1%的路径。**研究候选可以保留，财富目标没有完成。**
