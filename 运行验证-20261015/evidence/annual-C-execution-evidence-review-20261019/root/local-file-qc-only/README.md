# 固定的本机数据检查，结果不回传外部AI

目的：检查刚取得的单份公开报价对象是否能完整读取、标准字段是否存在，以及固定时段是否有报价/时钟记录。本任务不生成交易信号、假想成交、费用、收益或资金曲线，不运行模型，不联网、下载或安装。

固定对象与全部检查边界见`policy.json`。UTC [00:08,00:15)按local_timestamp及timestamp分别计数；日界仅约束按本地时钟分日的local_timestamp。00:10/00:12仅为观察锚点，不是已证输入可用或可下单时间。事件流没有规则分钟网格，更新间隔不能当断线证明；CSV缺断线事件，不能验收全时段持续可用。相邻重复仅是局部计数，不等于全局去重；不改变原文件或丢弃记录。

全部真实QC布尔、计数、时戳、指纹和结果报告留在用户本机私有目录，Root及审阅者不得将它们读回AI。工具只返回作业结束状态、预定报告路径；无论数据检查通过、失败、CRC错误或超限，生成报告后的退出码都为0，不通过状态信道暴露检查结论。技术运行/报告写入失败可非零退出；没有自动重试。

本次是既定公开研究的只读资料检查；本机访问/处理的有条件许可依据复用上一单元已核条款，不扩大外部披露或金融计算授权。Root只验收固定源码、合成小样和作业完成状态；真实数据结论由本机中文HTML/JSON交付用户，Root不会声称已阅读或独立验收其市场内容。

预先记录生成物：本目录的`policy.json`、`inspect_local_only.py`、`synthetic_privacy_check.py`、`job-public.json`、合成检查目录/回执及Python自有脚本的`__pycache__/`；原本机私有存档目录下新增`qc-v1.lock`、`qc-v1.private.json`、`qc-v1.private.html`。真实行情原件不修改，不生成副本。所有材料用于验收/交接，保留，无清理项。

合成核查如实记录：首次仅自造小样的输出ROOT未隔离，第二小样触发FileExistsError；无真实市场文件打开。旧小样目录及首次公开状态已保留。仅修正小样输出位置，隔离目录下4项检查通过；真实QC尚未因此执行。该技术修正不等于数据检查失败或市场实验重跑。
