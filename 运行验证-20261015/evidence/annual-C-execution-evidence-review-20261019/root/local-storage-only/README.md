# 单文件、仅本机存档的数据流

本任务属于既定公开研究的免费资料获取，不是模型、策略、收益或成交诊断。2026-10-19核对官方条款§1.1、§9.1、§9.4、§9.5及下载API后，个人内部访问/本机存储有正面许可文字；适用上游限制、安全义务及对外披露条件仍保留。本说明不是法律保证，也不扩大任何金融运行许可。

固定对象：`https://datasets.tardis.dev/v1/bitstamp/quotes/2022/01/01/BTCUSD.csv.gz`。公开文档的月首免key规则及官方元数据中的Bitstamp/BTCUSD/quotes映射为依据。最多一次整文件GET，不用HEAD、Range、账号、Cookie、API key、代理变换或拒绝后的其他路径。单文件/新增数据64MiB、单请求60秒、无安装/付费。遇明确拒绝、内容异常、超限或失败即停，保留原件，不自动重试。

这里的“一次”指一次客户端获取调用；标准库可能正常跟随服务端重定向，本次没有逐跳记录，实际HTTP跳数/终端对象版本标识UNKNOWN。没有在明确拒绝后换路径重取。不能据此称已逐跳验证传输来源链。

**数据边界：**压缩行情及私有传输原件仅放在用户本机`/Users/USER/Library/Application Support/XTX-local-research/bitstamp-20220101-quotes-20261019/`，位于Codex工作区之外，减少工作区索引/随包复制风险。当前不得通过cat、rg、Python打印、浏览器、图像或其他工具读入Codex/LLM，也不得外发、上传或打包进外部AI审查包。行情行、价格、统计、SHA/CRC等衍生结果均不返回外部AI。文件获取脚本仅返回请求成败、HTTP状态、固定本机路径等传输控制状态。私人收据可由用户本机查看；Root不得把其中数据指纹作为摘要再发送模型。

本机存档不等于允许后续把Data/DerivedData交给AI；不代表目标时段有行、连续、当时可用、BBO数量足够、可实际成交、完整费用或未来优势已核。后续如分析，应先定义符合许可的数据流和具体授权；本任务不解压行情、不做质量/成交/成本计算。

预先记录本任务生成物：`acquire_one_file.py`（普通HTTP存档助手，非金融代码）；上述本机私有目录下的`BTCUSD-2022-01-01-quotes.csv.gz.partial`（下载中/失败时保留）、完成后同目录`.csv.gz`（不覆盖已有对象）、`transport-private.json`（只留本机，不读回模型）；本README同目录的`transport-public.json`（不含行情或衍生统计的过程状态）。无计划删除项；取得的文件用于后续研究，不是可随手清理的临时缓存。
