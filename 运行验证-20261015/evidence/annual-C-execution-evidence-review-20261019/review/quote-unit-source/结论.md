# Bitstamp/BTCUSD quotes：数量单位与双时钟来源绑定

结论：**文档层面已有来源特定依据支持 ask_amount/bid_amount 的单位为 BTC，价格为 USD/BTC；不再仅是“spot 通常以基础币计量”的行业惯例推断。** 这是把 Tardis 的“原交易所最优价数量”定义、既有 Bitstamp/BTCUSD 现货映射和 Bitstamp 官方订单簿说明连接起来所得的解释；不是本轮读取了2022对象或核过2022年转换器。双时钟含义已有明确供应商定义，但不能据此把所有 timestamp 当作独立的撮合时钟或用户当时接收时间。

1. **已核：该字段是最优一档的挂单数量，非成交量或美元金额。** 复用2026-10-17取得的 Tardis [data-types](https://docs.tardis.dev/downloadable-csv-files/data-types.md)原始抽取：L205–221将 quotes 定义为由 L2 重建、在最优盘口变化时记录的 BBO；ask_amount/bid_amount继承交易所给出的对应最优价数量，缺侧可以为空。L41–46又明确 L2 amount 是更新后的价位绝对量而非数量增量。既有2026-10-18 Bitstamp元数据将原生 btcusd 和 CSV BTCUSD均标为spot，并列出quotes、incremental_book_L2及diff_order_book来源。**连接推断：该数量应理解为最优价位可见挂单量，不是累计多档深度、交易期间成交量、单一订单量或保证可成交量。** 本轮未把metadata覆盖范围当作目标日质量证明，也未重新请求metadata。

2. **新增正面来源：Bitstamp自己的 BTC/USD 订单簿说明使用 BTC 数量。** 当前官方[2014标日的TradeView说明](https://blog.bitstamp.net/post/new-trading-interface-tradeview/)L46–48明确订单簿按价位列出比特币买卖数量；L30–31同时区分 BTC 数量和 USD 花费/收入。当前官方[Understanding Tradeview](https://www.bitstamp.net/en-gb/learn/crypto-trading/understanding-tradeview/)L40–43将 BTC/USD 的amount解释为BTC数量、price解释为每BTC的USD价格，并另列USD价值及累计Sum。**来源绑定推断：按这些公开定义解释 Bitstamp/BTCUSD 的 Tardis quotes，ask_amount/bid_amount应以BTC计量；这有交易所专属文本支持，强于单凭spot标签。** Tardis schema本身没有单独写“BTC”，这些交易所说明也不是Tardis逐字段映射文件，故不能把连接推断写成“2022目标CSV的实际数量单位已独立验证”。搜索返回的当前Bitstamp API还区分普通base-amount与instant-buy的counter-amount，亦说明不能仅因字段同名amount就一律按BTC；本轮未访问这些交易接口。

3. **已核双时钟定义，精确到UTC微秒；撮合与可得性边界未获证明。** 上述Tardis原始抽取L19–20规定UTC/epoch微秒；quotes表L216–217规定timestamp取交易所提供的时间，交易所无该时间时回填local_timestamp，后者为采集端消息到达时间。因此不能预设两个时钟总是独立，也不能只凭字段名把timestamp叫作交易执行时刻、用户接收时刻或OHLC开/闭时刻。quotes是报价状态更新，不是交易成交记录。两个字段都不是用户策略进程在2022年当时实际收到消息的回执。既有metadata的当前London采集位置也不等于2022年全程机房/延迟证明；本轮不推算延迟。

4. **2022回溯范围：当前文档支持解释，历史流程与实际对象保持未核。** 新读两篇为当前仍可读的官方文章：一篇标2014-10-30，另一篇标2024-07-29；都带2026页脚/Robinhood品牌。这些不是当年网页存档，发布日期不保证正文未改；2024文章本身晚于目标日。既有metadata将历史可用起点列为2019-03-30、BTCUSD为spot，可支持产品身份和名义覆盖；没有提供2022-01-01当时WebSocket字段说明/转换器版本、原生microtimestamp具体生成环节或目标CSV逐字段核验。**可采用的表述是“供应商字段定义与交易所订单簿资料支持按BTC解释，2022对象与当时转换链未独立核验”，不宜继续写“毫无单位依据”，也不宜写“历史目标单位/可执行容量已证实”。** 这不改变既有QC结果UNKNOWN、数据流限制或后续分析授权；未提出或启动新实验。
