# 年度配置：独立时期、成交条件与净优势的最小验证方案

编制/公开资料读取日：2026-10-19（北京时间）。**仅方案，未运行、未采集行情、未核算新账户、未交易；没有创建自动化。**

## 1. 唯一问题及本轮决定

问题：既定的“按过去波动确定BTC年度目标比例、年内固定BTC数量与现金”的规则，能否在事前固定的新时期，较普通固定比例年度再平衡，取得风险相近、完整交易成本后的额外收益？

这不是验证AI预测，也不验证XTX做市。它可能利用波动持续性调整风险暴露，收入仍来自BTC价格与仓位路径，不存在客户另付服务费。新方案不得预设它有优势。

2014—2025已反复研究；2026已有覆盖、预处理及相关资料接触，不再叫全项目未见样本。换所、换CSV或换数据商也不能把同一BTC时期变成独立市场样本。故选择**未来事前固定的新现金子账户**，历史只提供因果信号暖启动。

原规则身份：简单日收益 `r_d=C_d/C_(d-1)-1`；年度日期e只取截至e−2的60个收益，需要e−62至e−2的61个日Close；总体标准差 `ddof=0`，波动下限1e−6，`f=min(1,0.40/(sqrt(365)*sigma))`。禁止用60个Close代替60个收益；禁止偷用e−1或当日未来数据。逐项定位见[规则审阅](../annual/rules-and-independent-period-review.md)。

源数据日柱必须先核区间开闭与UTC语义，按自然日映射到上述索引，不按不同供应商的标签机械挪一天。未能确认即不计算信号。原信号公式保留；新成交/费用适配会与旧Close全量成交代理产生不同账户，不能声称原样复制旧终值。

## 4. 可成交性：只验证小额条件，不能伪造真实成交

三组都按主动吃单估计，不假定排队成功、不享受maker折扣或专业低费。每次目标在读执行窗口报价之前封存；严禁看未来盘口决定信号/时点。

固定报价规则：从决策时刻+5秒才发起的新请求开始，以**第一个完整收到的有效快照**作为报价代理，最迟+15秒；不复用此前在途/缓存快照。必须有可解释的双边、未交叉、单调价格及非负数量，并保存源时钟与本地请求/接收时刻。本地UTC时钟误差须可核且≤1秒；单次请求往返耗时≤1秒，源时钟不得比接收时刻超前超过1秒，报价年龄须在[-1,2]秒内；时钟含义不能确认则不使用。该5秒是预设延迟假设，不是测得的用户订单延迟。首配三组的共同指令/填充须在S+15秒内完成，否则本次执行比较不可判定；不将pending首配拖到另一个年度。

成本估计用相应对手盘逐档价格计算加权成交价，并把每档显示数量仅按10%可用处理（保守容量假设，不是经验测量或真实保证）。不足以完成整笔时记录未成交；不在后面找一笔更好快照补满，也不把部分成交补成Close全额。任何必需执行事件不完整，该实验不能通过执行层；保留观测与停止原因，不改规则重跑。

必须核数量确为BTC、价格为USD/BTC及市场精度/最小金额。各事件记录目标订单BTC/美元量、显示与折减深度、加权价格、源/本地时差、原始快照和未成交量。不用日成交量、一根K线成交量或某次快照宣称资金容量。

**不下单的上限：只能得到“公开盘口支持的条件成交代理”。** 撤单、其他参与者争用、撮合顺序、真实订单接收及风控拒单不能由快照证明。即使通过，也不能写已真实成交。只检验5000美元子账户实际长成的订单；不额外模拟几十万/数百万美元账户，不外推容量。

## 6. 判据：先数据/执行/识别，再看收益

以下是**新前瞻候选准入门槛**，不是统计定理，也不改历史A/B Sharpe增量0.20与NOT_SUPPORTED结论。只公布一套主指标，不扫阈值择优。

### 必需前提

1. 在截止前封存规则、代码身份、来源、费用、起终点及判据；所有信号只用当时已取得的完整数据。准备可读旧数据，但不得试算新期收益、搜索更优k/窗口/起点。
2. 共同首配成立；2027、2028各至少一次A目标与k相差≥1个百分点，并按共同执行规则产生对应有效仓位差。仅因继承财富不同导致BTC数量不同不计新机制事件。A当年不需成交但C重配也可形成差异。必须两年都满足，否则**不可判定**；两年不是两个统计独立样本。
3. 信号窗口完整、每个必需事件成交代理完整、费用口径一致并能自融资复核。按层判断：报价、市场规则、交易费用缺项影响策略条件账；银行/FX/账户维护等适用性缺项影响个人全费账；税缺项只影响税后账。不得把未知填零，也不把后一层缺项冒称前一层已失败；许可未知不等于已禁止，出现明确适用禁令或拒绝则停止相应取数。
4. 主比较A/C净日收益年化波动之比在[0.80,1.20]，两成本档均成立。固定每日UTC收盘估值序列（费用进入所属日净值，首配/末清边界三组同口径），净收益为`V_d/V_(d-1)-1`，用`ddof=0`及`sqrt(365)`年化；分母为零或非有限即不可判定。若风险不匹配，结论是**不可判定**，不得用测试期波动事后调整k补通过。B同样报告风险比；风险不同则不宣称战胜相近风险的直接持有。

### 通过（只能升级为值得继续的前瞻候选）

三层分别给“策略报价/交易成本条件候选”“个人资金路径全费”“个人税后”结论。下述经济判据作用于已经完整取得对应成本的那一层；交易成本层通过而银行或税费未知，后两层仍为不可判定，绝不合并叫个人全费赚钱。

共同终点扣除定义范围内全部成本后：主档A年化净收益>0；A相对C年化净收益差≥1个百分点；A最大回撤不高于C；压力档A/C净终值差仍>0。这里年化净收益固定为`CAGR=(W_end/5000)^(365/实际间隔天数)-1`，差额固定为`CAGR_A-CAGR_C`，不能换成对数财富比、线性年化或终值差；共同起终点含相应成本。1个百分点是事前选定的最低经济研究门槛，**不是显著性证明**，不对应Gerko财富路径。

完整报告A/B/C两成本的终值、年化净收益、日波动、最大回撤、平均敞口、换手与分项费用；2027、2028结果全部公开，不要求每年赢、不把亏年删掉。B用于说明BTC上涨背景；A赢C不自动等于赢满仓BTC，也不能唯一归因为预测alpha。

### 失败、未达门槛、不可判定与停止
