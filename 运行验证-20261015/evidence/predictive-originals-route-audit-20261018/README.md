## 公开论文具体在研究什么

Gould与Bonart的2015年预印本用2014年Nasdaq的LOBSTER数据和逻辑回归，研究买卖队列不平衡对下一次中间价变动方向的预测。原文用随机80/20划分，并非按未来时间推进的实际交易评估。[原论文v1，2015-12-11提交，2026-10-18读取](https://arxiv.org/abs/1512.03492v1)

这一研究提供可理解的数学方法，没有为本轮提供完整成交与费用净利账。方向判断还缺价格变动幅度、可成交买卖价和成本，不能直接换算成能赚多少钱。

现有输入是按分钟抽样的Kaggle BTC记录；依已有质量核验为17113行、156列，整文件有71处大于60秒的间隔。冻结方案另有连续60秒的入选规则。这些快照不能直接还原分钟内第一次中间价变化的顺序，notional_0也未在本轮绑定为论文同义的物理队列量。不能由此把旧评分作废，或把失败唯一归因于数据。

论文的随机抽样方案属于其统计研究设计；若设计未来验证，需另外固定可因果执行的观察时点与时间顺序。这里不指控论文发生了已证实的信息泄漏，也不将其结果直接迁移到当下BTC。

## 新公开归档为何早停

Priced In作者原页明确是模拟环境，未执行真实交易，也未模拟手续费、价差及税费；故一次读取后停止，不继续下载日志来包装实际盈利。[作者原页，题头2025-06-24、更新时点未核，2026-10-18读取](https://anandchowdhary.com/open-source/2025/priced-in)

[已有候选路线审计](alignment/audit.md)没有从限定五份材料选出已定位、正常可取得的完整预测净利原件。它未穷尽全部公开世界，不代表方法普遍不可能盈利；既有403/429及明确关闭分支不重试。

## 只保留一个下一核验

先核LOBSTER官方免费样本是否提供可按时间排序的逐事件最优买卖价与对应队列量，并明确允许个人作预测研究。只检查数据语义、样本范围和适用授权，不进行模型、回测或盈利推算。若只有分钟快照或授权不清，则该样本不进入事件级研究。

这个核验即使通过，也只解决“有没有适合研究该问题的数据”。时间向前的预测优势、扣费后净收益和资金容量仍分别待证；不会据此宣称接近或完成Gerko财富1%的目标。

本轮只做公开资料和本地静态核验：模型、训练、回测、新账户账、交易、付款、外发、自动化修改均为0。旧FAILED/NOT_SUPPORTED保留；实际模型路由不可核，记UNKNOWN。所有新文件为研究证据，保留，无资产清理。
