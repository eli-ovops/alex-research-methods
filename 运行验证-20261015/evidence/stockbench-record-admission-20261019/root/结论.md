# StockBench：明确是零交易成本的历史模拟，停止盈利案例准入

**2026-10-19结论：StockBench不能作为已证实的个人扣费盈利案例。** 这次不只是“没找到费用文件”：最新版论文明确不建模交易成本、滑点和流动性限制。原始决策/成交输出也未在本轮固定目录闭合。保留为研究样本，停止本案新增执行准备；没有运行模型、回测或交易，财富目标未完成。

## 1. 原始论文实际口径

[arXiv版本记录](https://arxiv.org/abs/2510.02209)：v1于2025-10-02首发，v2于2026-03-02更新。本轮分别取得两版全文，以下以[固定v2原文](https://arxiv.org/html/2510.02209v2)为准，不将新版披露倒写成首发内容。

主区间是2025-03-03至06-30的82个交易日，初始100000美元、20只道指高权重股，是历史重放。模型读取新闻、基本面、价格等信息后决定增加、减少或维持资产；它没有交付一个统一的未来价格预测公式。测试发生在论文首发之前，不能称为发表后真实资金前向验证。

v2 §7（本地paper/03文本L1307）明确省略三类交易摩擦，故报告中的收益不是完整扣费净利润。§2.2又先把当日官方开盘价给模型，再按同一开盘价把目标金额换成股数执行。它可用于理想化比较；本轮没有证明看完该价格和完成分析后还能按同价完整成交。系统检查可用资金不等于市场深度/排队成交验证。

作者近期数据/contamination-free的表述也不能独立证明无污染。v1/v2对部分模型采用2507变体的表述与主测试日历之间存在待核的时间身份问题；精确API快照、调用UTC、权重及训练知识截止没有取得。**这既不能认证无泄漏，也不足以指控实际已泄漏。**

## 2. 收益为什么不能归功于可复制预测优势

作者表2及[项目网站](https://stockbench.github.io/)给出部分模型模拟回报高于静态持有基准的汇总，也比较回撤与Sortino。它们是同一有限区间的作者结果，不是我们新计算；三次运行平均不等于事前选定模型在未来重复成功。

即使部分模型回撤较小，也可能同时具有更低仓位、更多现金或不同资产敞口。当前比较没有把这些因素与预测贡献完全分离，再加上省略成本，不能识别个人真实净优势和容量。模型排名不能直接成为事前策略选择规则，更不能外推年化或用户财富目标。

经济假说是新闻/基本面分析帮助较好配置资产；究竟哪种可用信息未被价格反映、谁为何持续付出价差，以及优势是否覆盖执行和模型服务成本，尚未由原账证明。本轮不把通用市场解释补写成作者的已验证赚钱机制。

## 3. 公开代码与原运行记录分开

论文、[作者仓库](https://github.com/ChenYXxxx/stockbench/tree/ce8b2b3483590646ad3b650ac8221f43f76fd091)及官网身份互相绑定，固定Git提交为2025-10-28，不自动等于论文的精确原运行。主README与storage说明会生成交易、净值、配置和日志，是有用工程说明。

但实际固定storage层只有README/cache/parquet，cache完整一层没有说明中的llm节点，不能到by_run读取决策；storage也未列reports。本轮未取得原始actions/trades/fees manifest。旧整仓库递归tree因本地2MiB保护而未完整取得，未知部分和外部/历史渠道均不作不存在结论。路径与原件核对见root/04及artifacts/llm-cache-followup/。

Apache2.0是README代码许可自述，LICENSE正文未读，市场/新闻/模型服务授权另待核；不因为公开缓存就默认可以用于个人交易或商业再发布。未请求服务API、账号或凭证。

## 4. 可以学什么，为什么停止本案实验准备

可以学习把每次可见信息、决策、目标仓位、执行和净值分别保存的研究流程；也可用该案例认识理想成交和真实执行的区别。**当前没有足以复制的已验证扣费优势，不建议为了补原件而自己重跑后再冒充原结果。**

停止仅针对这一案例的盈利准入，不是否定全部语言模型或个人研究。历史零成本模拟仍有基准研究价值，但它不满足用户所找的扣费盈利证据。若作者以后提供绑定精确时点、模型/输入与执行成本的原始记录，或用户明确指定其他分析任务，再重评。

下一步只读研究把成本与决策/成交时序披露放到收益宣传前面，优先核一个具体预测信号的经济依据和原始记录，不继续扩读框架目录。不会以排除一个不合格案例宣称全面调查完成。
