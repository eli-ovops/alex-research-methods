## 数据“看起来每秒一条”还不够

[已有固定工具语义审查](semantics/semantics-audit.md)只读三份原来保存的代码，未执行它们。固定工具commit为`078081e5715cadeae9c798a3d759c9d59d2041bc`，与实际2021导出版本/配置的绑定仍UNKNOWN：

- 该实现的`system_time`由本地处理tick时生成，先入缓冲，再批量写盘；不是直接的交易所事件时间或精确写盘时间。
- 快照器先把已有盘口复制到跨过的时间网格，随后处理触发tick。它不是本范围已证的mean/min或普通resample.last；标签也不认证当时已经输出可用。
- 跨越缺消息间隔时，同一状态及流统计可被复制到多个标签。因此不能仅凭时间间隔整齐断言每秒都收到独立新信息，或逐行累加为新订单流。
- 该范围只转交`PriceLevel.notional`与renderer结果；币量/报价币金额、变换、midpoint/spread公式的具体依赖未读。不能按字段名称补单位。

以上是条件性工具代码证据，不是实际CSV历史生成认证，也不据此判定具体预测实验发生未来信息泄漏。实际字段值、时间范围、分箱、缺口和完整质量未验。一秒快照不能还原每个市场事件，先前一分钟结果保持原结论。
