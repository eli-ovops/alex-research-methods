# 固定V2池的预测与报价控制

**结论：仅持有既有V2池LP份额，不能把自己的预测装入该池、让它按个人预测改变双边报价。** 但“不能装预测参数”不等于“任何操作都不能影响储备/价格”。真实换币、增减库存或转币后sync会改变状态，且带来资产、费用和风险变化；不能把它们描述为免费改价。
