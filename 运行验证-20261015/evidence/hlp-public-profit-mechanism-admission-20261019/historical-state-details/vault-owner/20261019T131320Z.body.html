Authorizations

​
X-API-Key
string
header
required

Your Hypedexer API key. Create one in the console at https://app.hypedexer.com. Authorization: Bearer <key> and the api_key query parameter are accepted as well.

Query Parameters

​
vaultAddress
string
required

Vault address (0x…)

​
startTime
integer | null

Epoch milliseconds

​
endTime
integer | null

Epoch milliseconds

​
limit
integer | null
default:500
Required range: 1 <= x <= 5000

Response

200 - application/json

OK
