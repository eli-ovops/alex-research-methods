# 实时输入与个人可复制性：跨市场假设的只读核查

读取日期：2026-10-23；本轮时钟观测2026-10-23 03:48:11 UTC，不冒充每个页面的精确取得时刻。网页全文发布日期/更新日均UNKNOWN；文内API迁移日期不是页面发布日期。当前只研究，未调用行情接口、连接WebSocket、读取行情文件、运行模型或修改既有方案。

## 结论

公开行情字段存在取得路线；尚不能证明个人能及时利用。新增证据是：历史样本的接收时钟属于供应商的伦敦采集环境，而Tardis没有托管实时行情API可直接交付同样的接收时序。因此，未来离线挑战通过，也只能先成为供应商采集条件下的信息候选，不能直接转成个人赚钱结论。继续保留已审信息挑战；不为此购买服务、修连接或扩建采集系统。

## 本轮核到什么

1. **时间戳身份。** Tardis CSV规范将`timestamp`定义为交易所时间（缺失时可能以本地时间回填），`local_timestamp`为消息到达时间。它不是用户电脑的接收回执。[CSV字段规范](https://docs.tardis.dev/downloadable-csv-files/data-types)。据此，既有方案按供应商local时间因果取数有明确含义，但不能证明个人信息到达时刻。

2. **两源采集地与交易所位置。** Tardis目前称Bitstamp及Kraken都在GCP伦敦europe-west2采集；称Bitstamp服务器在法兰克福AWS eu-central-1，Kraken自2025-11-01在伦敦Equinix。此为供应商对位置的披露，不是本轮独立测得延迟、撮合机位置或供应商逐台服务器同步误差。[Bitstamp采集说明](https://docs.tardis.dev/historical-data-details/bitstamp)，[Kraken采集说明](https://docs.tardis.dev/historical-data-details/kraken)。**推断：**两源传输路径可能影响观察到的领先关系；相同云区域不证明同机同钟，也不能据位置断言全部关系都是假信号。

3. **Kraken历史quotes不是原生ticker直接导出。** 规范称quotes由L2重建，最优价变化才记录，并明确区分原生book_ticker。替换成一个名字相似的ticker可能改变更新频率与到达顺序。[CSV字段规范](https://docs.tardis.dev/downloadable-csv-files/data-types)。因此，低成本复用应先匹配L2重建语义，不能把接口能返回bid/ask当成历史输入已等价。

4. **公开L2具备所需基本字段。** Kraken官方book通道列有价格、数量、快照/更新、checksum和行情timestamp；更新须按序处理。订阅确认中的time_in/time_out是请求/回执时间，不能代替每条行情到达用户的时间。[Kraken官方Book文档](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/book)。Bitstamp官方公开订单簿与差量通道已于10月21日正常浏览器实读，见原观察记录；本轮没有重连接口或重测其功能。

5. **免费工具与托管实时流不同。** Tardis FAQ称其没有托管实时行情API；开源客户端/本地Tardis Machine可免费使用，并直接连接交易所公共WebSocket，无需Tardis key。故买历史数据key不自动取得供应商实时接收时序。FAQ也说明持续采集需要处理断连、限流、延迟与API变化。[Tardis FAQ](https://docs.tardis.dev/faq/general.md)。这是公开工具路线，不是个人在中国内地已可稳定访问、零维护、拥有完整商业许可或能够交易的证明；本轮未全面复核交易所商业数据合同。

## 我们能复制什么、还不能声称什么

| 环节 | 当前依据 | 仍缺什么 |
|---|---|---|
| 用L2更新重建最优买卖价与数量 | 公开规范有相应字段；历史CSV规范说明构建方式 | 个人采集完整性、同样的去重/快照恢复及重建结果 |
| 在当时已收到信息上计算特征 | 可以事前定义，现有待执行方案已固定 | 本机真实接收记录；不能用交易所事件钟假装提前收到 |
| 跨市场信息提高预测 | 尚未执行本次独立挑战 | 固定未来日相对两个基准的结果 |
| 在优势消失前成交 | UNKNOWN | 本人接收、计算、下撤单/成交的联合时延及队列证据 |
| 完整扣费赚钱并放大 | UNKNOWN | 真实费率、滑点、成交/退出、库存风险、运营成本、深度及竞争影响 |

**教学逻辑，不是收益估计：**只有当信息在本机可得后，剩余可利用时间足以覆盖计算和订单到所，并且届时实际买卖价差所得超过完整成本，预测才可能变成钱。不能先假定“一秒预测就有一秒可操作时间”；也不能把某个固定延迟简单乘以一个未经估计的衰减率来宣布净优势。
