# 封存模型：怎么预测，哪些证据现在就能拆清

2026-10-23，只读研究及已保存小标量的代数解释。未读原行情或未来文件，未运行训练、模型前向、标签、策略或收益核算；未改变原定未来挑战、模型与评分门槛。

## 已得到的结论

模型的预测公式已经能用白话拆清：看本市场最近变化和盘口，再加入另一市场最近变化及两场价差偏离，估计本市场一秒后的最高买价相对当前最低卖价的变化。封存M1中三个跨市场系数均为正，说明这次拟合确实使用了它们，其方向与“外场变化含有本场后续价格信息”的假设相符。**这只是已拟合公式的事实，不是样本外预测优势或因果领先已被证实。**

另一个已拆清的问题是：数据年龄门槛并非网络时延仪。训练日被排除的格点主要首先触发Kraken当前记录的年龄条件，而两腿文件的更新触发条件不同。因此不应据这些计数继续修连接，也不能把它们写成个人漏单数量。原未来检验仍值得按固定方案完成，它检验的是共同满足输入条件时的增量信息。

## 一、模型实际预测什么

源码`challenge.py`的make_labels定义：

`Y = 10000 ×（Bitstamp在t+1秒的最高买价 / t时已收到的最低卖价 − 1）`。

这里的t及到达顺序属于供应商local时钟。未来最高买价取不晚于t+1秒的最后记录；目标记录还须满足原年龄门槛。这是一个报价比率，不是用户已经买入、卖出的成交收益。模型M0/M1都是普通线性拟合；没有借用或公开取得XTX私人权重。

不变价格基准N把未来最高买价预测成当前最高买价，因此也计入当前买卖报价差。比较时不是把一个含价差的目标拿去对零误差幻想基准。

## 二、冻结权重说明它怎么形成判断

原件：weights.json，SHA256 `15848629f9686dda8f6efaec2bc596648255cd2aca96e93b63ad9cb2d02db155`。下表是直接从封存文件读出的系数，非本轮重新估计。输入先按训练均值和总体标准差标准化；表中数值表示单个输入增加一个训练标准差、其他输入固定时，公式输出Y改变多少基点（1基点=0.01%）。

| 输入信息 | 只看本场M0 | 加入外场M1 |
|---|---:|---:|
| Bitstamp过去100毫秒中间价变化 | +0.017664 | +0.005766 |
| Bitstamp过去500毫秒中间价变化 | +0.058509 | +0.003530 |
| Bitstamp当前相对买卖价差 | −0.080901 | −0.083377 |
| Bitstamp最优买卖档数量不平衡 | +0.112099 | +0.072836 |
| Kraken过去100毫秒中间价变化 | 不使用 | +0.060696 |
| Kraken过去500毫秒中间价变化 | 不使用 | +0.107778 |
| 两场当前对数价差减过去60秒的均值 | 不使用 | +0.049821 |

两个模型的标准化截距均约−0.0226765基点。输入变化的锚点取数沿原方案，不保证每个锚点恰好有成交所事件；允许的记录年龄不等于毫秒级实测延迟。

**教学解释，仅解释公式而非真实预测：**在其他输入保持不变的数学条件下，Kraken的500毫秒变化增加一个训练标准差，M1输出提高约0.107778基点。这不是每笔利润、平均可赚幅度或实际市场可以独立操纵的一项变化。相关特征常一起变化，不能把系数排名叫真实重要性、贡献率或因果证据。

加入外场后，本场两个历史变化系数变小，外场变化系数为正。这与信息重叠/相互替代的解释相容；也可能受相关性、特定训练日或采集时序影响。没有特征协方差、独立挑战或获准的额外归因实验，不能从系数断言哪一项带来了多少准确率，更不能把训练拟合称为已赚钱。

完整原单位斜率及标准差的代数换算见本目录`coefficient-algebra.json`。计算仅对封存的7个系数及既存计数作标量运算，没有向模型传入样本，没有产生新预测。

## 三、现有计数揭示的是输入门槛，不是连接故障

封存训练原件给出43,170个固定格点，37,564个满足共同输入条件，覆盖87.0141%；5,606个未通过。训练标签可用的37,543个才进入两组同一拟合人口，另21个输入合格但训练标签未知的格点没有被倒改成“未发预测”。

按原检查顺序的**首个互斥排除原因**：

| 首个原因 | 格点数 |
|---|---:|
| Bitstamp当前记录缺失或距t超过1秒 | 42 |
| Kraken当前记录缺失或距t超过1秒 | 4,798 |
| 其他当前/回看锚点条件 | 766 |
| 合计 | 5,606 |

4,798占排除点85.5869%，但该占比受固定检查顺序影响，不能读成网络故障的因果分解。

供应商说明：book_snapshot_25在被跟踪的25档任一档变化时记录；quotes在最优档变化时记录。因此两者“最近有记录”的含义不同。没有新quotes可能只是最优档未变，并非必然断连；也不能排除缺口，单凭本计数无法区分。[Tardis字段规范](https://docs.tardis.dev/downloadable-csv-files/data-types)

**推断及实际影响：**当前门槛会限定可评分人群，可能偏向较活跃的最优档时段。M0/M1使用完全相同的人群，比较保持同条件；但结果不能自动外推到全天每一秒。这个区别不构成已证实现错误，也不授权放宽门槛或重跑。原始心跳/收包日志/供应商丢包状态没有在本轮读取，连接是否故障保留UNKNOWN。

## 四、晚到会影响什么，现在能判断到哪里

输入只用了100/500毫秒变化，却预测供应商时钟下一秒的报价。若用户收到有关更新更晚，模型能使用的信息集和可操作时间都可能变化；实际影响大小还取决于信号持续多久、两路相对延迟和成交到达时刻，不能只用一个延迟数字作比例衰减。Kraken官方book文档列的订阅time_in/time_out是订阅请求及确认的时间；它们不能代替用户每条行情的接收时间。[Kraken官方Book文档](https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/book)

目前能确定：这些问题影响从历史预测向个人可用预测的迁移。不能确定：晚到多少毫秒才失效、当前电脑能否及时取得、模型的真实收益损失。没有新接入测量或时延实验，就不填假数字；本轮不为此改连接或追加运行。

## 五、公开原始研究给了什么参照

本轮对已知Albers等2021年v1原文作定点补读，不包装成新论文发现。作者用14个市场、70个输入作线性预测，检验500/1000毫秒期限；训练2021-02-22至27日，后两天测试。其Bybit半秒样本外R²报告为0.289，**这不是预测命中率，也不是我们的成绩**。[原始论文](https://arxiv.org/abs/2108.09750v1)

同文历史taker策略在默认费用下结果全部为负，VIP费用下部分为正；该分析还遗漏冲击/时延，作者另一个实盘环境自报同云区连接小于1毫秒。它给出“短周期跨市场预测可被研究”的实例，同时提示普通个人获利需要不同证据。不能据该文当年的费档或自报速度认定今天可复制。核读依据是已保存v1官方TeX，未取得或冒充2022正式版；完整费用现金账未在本轮核到。论文同样比较多个模型和参数，不升级成与本次事前冻结相同的单方案证明。

当前可借鉴的是输入、基准、时间留出与执行条件分开的研究方法。我们只有两场七特征、不同日期，不能套用作者R²；更不需要先复制其低延迟设施，才允许承认我们自己的预测层面进展。文献Owner的[核查记录](../literature/已知跨市场论文-期限样本外与执行限制.md)区分已知复核、作者自报与本轮未核事项。

对精确标签额外只读补核后仍为UNKNOWN：原文给出了过去特征所用的成交量加权价，也另述了策略买卖报价，但本轮未定位将其绑定到fret预测目标的定义。不能认证它与我们的future_bid/current_ask相同，也不反向断言已证不相同。[精确缺口与定位](../literature/label-definition-addendum.md)。这限制论文数值的直接比较，不阻断我们定义明确的原定独立挑战。
