# Basis公开案例：报价机制可学习，公开收益不能作为个人盈利原型

2026-10-23；本轮只读原件审查。原财富目标仍未达成。本报告没有声称复刻XTX、取得交易优势、获得真实利润或容量；没有运行Notebook、预测模型、策略、回测或交易。

**结论：HftBacktest《Market Making with Alpha - Basis》把“价格参考→报价→库存”接成了清楚的公开代码，但本版本不能晋级为个人可复制的盈利证据。已定位两项具体问题：发布者采用最高档maker返佣，原嵌入收益图的排除费用项曲线最终为负；预计算100ms桶的last价格却按桶左端消费，在官方默认语义下存在提前使用桶内未来观测的实现路径。** 这两项都不要求我们先开发或再跑一轮回测才能发现。

## 2. 谁付钱、凭什么可能赚钱

这是相关市场参考价驱动的单腿做市示例：

现货中间价＋期货相对现货的过去5分钟平均价差 → 对当前期货合理报价中心的估计 → 在两边挂买卖单 → 持仓偏多时压低报价、偏空时抬高报价 → 模型撮合和库存估值 → 加入交易费用/返佣。

可能的经济来源有两部分：与需要立即成交的对手交易，获得成交价相对之后价值的差额；交易所按maker成交名义额支付返佣。二者都须覆盖逆向选择、价格变化和库存成本，不能把买卖报价距离机械当收益。本Notebook只给出合成回放结果，没有分离每项因果贡献。

参考现货只是输入，并未买现货对冲期货；回放只有asset_no=0一条linear资产。因此它不是公开的无风险两腿套利账，也不是XTX披露的生产模型。

100ms是采样/决策间隔，5分钟是basis均值的历史窗口；两者均不是已证实的预测有效期限。没有方向命中率、独立样本外预测精度或预测增量对照。它使用简单均线而非大语言模型或训练出的深度网络。

## 3. 返佣：原图本身已给出重要信息

Notebook首注与配置明确采用maker -0.00005、taker 0.0007。按官方约定，负费用为返佣，maker即每成交名义额0.5bp返佣，bp为万分之一。两个月主输出展示ReturnOverTrade=0.000032，即每成交名义额约0.32bp的含费用项收益；这不是每次往返收益率，也不是本金回报。

本轮固定tree源码核得：Ret先计算equity_wo_fee-fee，再作末首差；ReturnOverTrade为该利润除成交名义额。GTX限价单若到所穿价即Expired；在本NoPartialFillExchange中被动成交标maker=true。以上是静态执行模型，不是认证实际成交。

更直接的原件是Notebook cell15自带PNG：本轮只原样提取并观看，没有重画或重跑；橙色Equity w/o fee曲线末端明显低于0，包含费用项的曲线最终为正。这里去掉fee也去掉负费率带来的返佣。因此发布者自身这个图不能支持“仅靠价格估计与成交就有正毛收益”的主张。

作为同路径、全maker且统计定义一致的条件算术，约0.32bp减去0.5bp返佣意味着排除返佣后的约-0.18bp/成交名义额；数字来自已发布的舍入汇总，并非新核算或精确账务验收。原图对负方向提供直接交叉支持。**不把这个条件解释升级为作者实盘亏损、整个策略无效，或已审清全部费用。**

尚缺原run可绑定的逐笔成交与fee原账、精确环境、原始record数组及终端实际退出。资金费、融资、运营成本也未由此验证。未完成这些不代表费用必然很高，但禁止把它们记成0或把图当个人完整净利润。

## 4. 时序：代码有明确的提前可用路径

固定Notebook两腿均group_by_dynamic(every='100ms').agg(mid_price.last())，未显式label/closed、未推迟可用时间；结果按桶时间写出。策略消费timestamp≤current_timestamp的最后一行，立即以spot+basis形成报价中心。

Polars官方0.20和当前stable文档默认均为closed=left、label=left，period未给即every。因此桶[start,start+100ms)的last值可以来自桶内晚于start的观测，却标在start。

教学时序例（并非实测）：.000–.100桶里最后价格在.090到达，预计算行标.000；策略若在.020读取，就提前用了70ms后的信息。100ms决策间隔、滚动平均和下单延迟都不会自动纠正决策输入的实际可得时间。

**已证的是在官方文档默认条件下的静态非因果路径；未知的是原Polars实际版本、数据更新/决策相位、真实提前次数及其利润影响。** 不能说每笔恰提前100ms或全部正收益由前视造成，也不能把“原run没有锁环境”当完全无需指出源码问题的理由。

这意味着：即便返佣个人可获得，当前公开输出也未过因果时序验收，不能直接承接为可复制盈利结果。修源码并运行是另一研究单元，本轮没有执行。

## 6. 明确取舍与唯一后续问题

**停止把这份固定Basis输出作为“现成可复刻、正利润已证实”的候选，不申请运行它来追图。保留其公允价→库存→报价的软件结构作为研究材料。** 原成交流暂停实验及停止不变；不把这份案例的发现倒写成原两日失败原因。

唯一值得继续收敛的问题是：**在决策时确已可见的信息下，合理价估计相对“本市场当前中间价”，能否在同一执行/库存约束下提供足以覆盖个人成本的增量？** 所需证据必须把预测增量、执行和费用分开；单独有准确度、正返佣曲线或库存更少均不够。

目前未取得这个正证据，不称已有低成本赚钱环节或可扩大资金。可继续做公开原件与因果输入的研究；任何新的拟合、收益核算或策略执行都不是本轮自动下一步。此结论使下一步避免重复跑一个已经在来源层暴露问题的正曲线。
