## 后续结果是什么口径

主办方论文确认2023有提交截止后的模拟评估。选定队伍公布后段收益0.04%，DJIA为0.80%；正文结束日写11月21日，表4写22日，且表4明确标注夏普比率错报。[论文，2025-09-05发表，2026-10-18读取](https://ietresearch.onlinelibrary.wiley.com/doi/full/10.1049/aie2.12004)

因此不能把它误称全无前瞻，也不能把这些汇总数当完整实费净盈利。收益少于指数本身还不能证明方法差，因为风险敞口未统一；短期小正数同样不证明稳定优势。上述为证据判断，未重算收益。

## 我们能复制什么

可以借鉴“市场输入→固定决策→事前保存动作→后续独立核账”的研究结构。要证明赚钱，还必须把这些动作绑定到当时可实现的成交及完整成本，和风险相近的简单持有比较。当前脚本没有交付这条完整证据链。

不应复制的是公布的收益数字，不能把现有PPO_PARAMS当已载入权重的训练配置，也不能把环境费率当本人实际交易成本。关于资金能放大多少，目前只能写UNKNOWN。
