# 固定 gDAI 案例：真实现金变化与成本归属

读取及核验日：2026-10-18 UTC。结论：**已有可核对的双币种现金变化，仍未证明完整扣费净利、可重复优势或容量。** 本轮只核真实历史原账，没有运行模型、策略或回测，没有新建虚拟交易账户。

## 实际发生了什么

本例不是教学示例。沿用上一阶段在看到金额前选定的同一笔赎回，没有换样本。四个区块的 hash 已与原交易回执相符。

| 环节 | UTC 时间 | 同一资产的实际 Transfer |
|---|---|---:|
| 外部资金池体系转入，按公开接口解释为借入 | 2023-01-04 00:32:46 | +850 DAI |
| 存入 gDAI 金库 | 2023-01-04 00:34:11 | −850 DAI |
| 赎回金库份额并收到资产 | 2023-01-06 15:04:03 | +851.847535814009530728 DAI |
| 向资金池体系返还，按公开接口解释为偿还 | 2023-01-06 15:05:36 | −850.110166431858826003 DAI |

因此，金库存赎差额为 **1.847535814009530728 DAI**；资金池返还额比原转入多 **0.110166431858826003 DAI**；上述四笔资产流合计为 **+1.737369382150704725 DAI**。最后一项不是全账户余额变化，也不是全部净利润。额外返还额尚不能全部、精确归为这笔金库持仓的利息。

原始交易链接：[资金转入](https://arbitrum.blockscout.com/tx/0x8c00149ace02e00b73973543bbe336070e42a0c0a6b89cb44228f23f03678d8e)、[存入](https://arbitrum.blockscout.com/tx/0x9ba47ee40d059ee36d2e05c5c56f844ed5dba071c482a3ffea8f3cdf60c3d516)、[赎回](https://arbitrum.blockscout.com/tx/0xea25cb68567595cb126982947271f4b74f1376479150b6b040a85463f314465c)、[资金返还](https://arbitrum.blockscout.com/tx/0x58c9f923902d04d37a4ddb66404555017d6c7b2f589c3fd47b71752615e62c7b)。浏览器链接仅便于定位；计算依据是前阶段保留的官方 RPC 原件。

在计算前固定两个范围，全部列出。每笔按原回执 `gasUsed × effectiveGasPrice`，不重复加入 `gasUsedForL1`。

| 费用范围 | 实际回执总费用 |
|---|---:|

第二个范围包含中间其他合约交易和资金池相关操作，对金库单笔归属可能过宽；第一个范围没有覆盖资金成本。两者都不是完整经济成本证明。不得把两个币种金额直接相减，也未把 DAI 当成固定1美元。

本轮可报告的有限结果是：**上述四笔资产流 +1.737369382150704725 DAI；九笔已观察发送交易的链上收费 −0.0004524838 ETH。** 没有取得同期 ETH/DAI 换算原件，没有合并成单一币种的净利润或投资回报率。

## 哪些证据变强了

- 独立 Sourcify 记录绑定借款资产地址 `0xda10009cbd5d07dd0cecc66161fc93d7c9000da1`，提供商记 creation/runtime `exact_match`，部署块1336824早于本例。`contracts/l2/dai.sol:Dai`第44行的 `decimals = 18` 为常量，因此本轮可以把原整数显示为 DAI。2024-08-08的 verifiedAt 是验证时间，不是事前公开日期，也不是本地独立复编译证明。
- 当前公开 Aave `IPool` 接口可以解释原 Borrow/Repay 事件字段；借入原量和实际 DAI 转入相等，返还原量和实际 DAI 转出相等。完整历史 Pool 实现仍未绑定，不能把接口语义匹配说成历史运行代码已完整验证。
- 债务 token 的销毁原量不等于实际偿还 DAI，不用它替代实际费用或直接计算利息。

## 尚缺什么，以及它怎样影响判断

1. **资金与抵押边界**：借贷完整负债、抵押资产的历史身份/精度/取得与持有成本仍缺。不能用借入850 DAI作全部自有本金，计算个人投资回报率。
2. **其他持仓关联**：nonce40在另一个协议的交易可能与整体资金配置有关。已保留费用，但没有判断其仓位盈亏或与本例的经济关系。
3. **全费及计价**：同期 ETH/DAI 换算、边界外实际相关费用、可能补贴/退款及完整退出仍缺。不能把缺口填零。
4. **优势来源与重复性**：gDAI 初始源码允许外部资金注入，933条 RewardDistributed 不能全部自动归为交易费。本笔增值由哪类真实付款构成、规则事前公开的独立证明、扣费后重复表现与可执行容量都未补齐。

这笔记录支持继续研究“提供资金、承担对手方与协议风险，获得费用相关回报”的机制；它不是已取得的价格预测模型，也没有证明可复制 XTX 的预测优势。即使以后本笔完整净利核实为正，也不能由一笔短期记录推出稳定收益、未来增长率或达成 Gerko 1%财富的路径。
