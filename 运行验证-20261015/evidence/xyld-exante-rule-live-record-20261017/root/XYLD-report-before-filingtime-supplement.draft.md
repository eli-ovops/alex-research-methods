# XYLD真实基金盈利核验：股票增值、期权损益与原账缺口

**结论：找到比回测更强的实际基金盈利证据，但仍未满足你要求的完整可复现案例。这个样本说明“备兑组合能在某段真实期间盈利”，没有证明“卖期权本身持续有优势”，也没有证明能靠它达到Gerko财富的1%。**

本轮在读取表现之前固定候选为Global X S&P 500 Covered Call ETF（XYLD），期间固定为2025年结束的最近完整财年，未因结果换基金或换年。实际期间为2024-11-01至2025-10-31。资料读取日期：北京时间2026-10-17。仅研究；模型、策略、回测、交易、账号登录和新增付费均为0。

## 一、事前公开规则与后续运作

2024-03-01的正式摘要招募书已公开：持有指数股票敞口，按月卖出平值、现金结算的指数看涨期权，覆盖最高至100%；基金为被动跟踪，年运营费率0.60%。这不是聊天模型荐股策略。该文件也区分基金费用、证券交易成本及投资者自己的券商费用。

来源：[SEC中的2024年正式摘要](https://www.sec.gov/Archives/edgar/data/1432353/000143235324000176/a497ksp500coveredcall.htm)。

但有版本边界：2025-09-30投资政策改为更明确使用代表抽样、可含底层ETF；更早历史也发生过指数切换。因此只能称“事前公开框架之后的实际运作”，不能把所有历史说成一套完全固定参数的独立样本外检验。

## 二、钱究竟从哪里来

财报及股东报告给出的结果如下。基金总回报是分配再投资口径，非个人到账收入；美元分项含未实现估值变化，非已全部落袋现金。

| 该财年项目 | 核实结果 |
|---|---:|
| 基金总回报 | +10.72% |
| 同期S&P 500总回报 | +21.45% |
| 投资相关已实现及未实现损益合计，含关联投资 | +572,568,323美元 |
| 卖出期权已实现及未实现损益合计 | −302,503,664美元 |
| 净投资收入，已扣基金报列费用 | +21,938,898美元 |
| 加上顾问支付62美元后的运营净资产增加 | +292,003,619美元 |

这些是同一真实基金的报表数字及分项静态相加，**不是我们运行的回测**。相关财务报表有PwC审计意见；这并不等于审计师公开了所有逐笔成交。基金费后总回报不应再重复减一次0.60%，投资者自己的券商费、税和买卖价差也不能假装已经包含。

来源：[2025股东年报，第1—2页](https://assets.globalxetfs.com/funds/documents/xyld/prospectus-regulatory/Annual-Shareholder-Report.pdf)；[法定财务报表，PDF第91、100—101、115、131—132页](https://assets-cms.globalxetfs.com/Annual-Financial-Statements_covered_calls.pdf)。

**第一性原理解释：本期组合的正结果主要来自股票投资增值，期权腿抵销了部分增值。** 买期权的人付权利金，换得按约定条件分享上涨的权利；市场上涨时，卖方可能需要支付结算款。权利金到账是合同开始时的一笔现金流，不能直接当作整笔合同的最终利润。

应评价股票与期权组合。单看期权腿亏损，不能断言整个策略无效；单看组合盈利，也不能证明期权预测有优势。与股票指数的回报差距同样不能单独判断风险调整后谁更好，本轮未计算回撤或风险匹配后的超额表现。

另一个赚钱主体是管理服务提供者。基金报列相关监督管理费用18,318,445美元；这是基金的支出，不等于管理公司的净利润，更不是老板个人分红。投资人承担市场风险获得回报，与服务提供者收费，是两种不同的收入机制。

## 四、你能低成本借鉴什么

**可以借鉴的是事前固定规则、低频调仓、组合评价和完整净收益记账。** 理解这些环节不需要训练AI，也不必重新开发交易系统。它们是研究方法和风险结构，不是承诺回报的秘诀。

若研究的是“获得类似经济敞口”，公开基金结构提供了一种与自己逐只买股票、逐笔卖指数期权不同的实现方式：通过券商在二级市场持有基金份额。这里仅说明渠道结构，未核你的当前可买权限、实际报价、税务和全成本，也没有建议现在购买。持有基金份额没有复制管理人的收费业务，更没有复制XTX的预测、报价、执行和客户优势。

若研究的是“亲自复现这套交易”，缺少精确执行记录就无法知道理论价格与真实成交之间的差异；缺少适用费用就无法算出个人净收益；换成更小的股票或另一类期权后，也不能沿用XYLD的历史表现。

## 五、对财富目标的判断与下一步

**保留为更强的实际运作样本，仍不准入为已证明的个人赚钱项目。** 本期正回报不证明未来稳定盈利；低成本参与一种风险结构，也不证明能扩大到财富目标。还缺持续、可复现的净优势、资金承受回撤的能力，以及规模扩大后优势是否仍在。不能只靠提高杠杆补这些缺口。

下一步只补一个最关键证据：**查同一案例、同一期间是否公开了逐笔成交和费用原件，且能与持仓和报表对上。** 优先查官方明示的持仓/法定披露入口，不从净值反推交易、不运行回测、不向机构发信或申请账号。若只有时点持仓与汇总，便收口为“原账未齐”的研究样本，继续寻找其他满足原标准的案例，不为了通过而改标准。
