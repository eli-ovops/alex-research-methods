# 从公开买入信息到个人净利润，必须闭合哪些环节

这是2026-10-19的只读研究定义，不是已执行实验或交易建议。本页没有计算新收益。

## 赚钱假设及替代解释

候选机制是：部分管理层自费买入，较薪酬、税务、分散资产等常规变动含有更多公司前景信息；其公开后若价格调整尚未结束，外部人可能捕获剩余修正。这是CMP原文支持的历史机制假设，不是XTX已公开采用的策略，也不是每次买入都有效。

实际要检验的是“外部人已经能看到披露以后，按固定规则进入，能否扣除成本后仍优于承担相近风险的直接持有”。过去股价上涨、牛市、特定行业/规模/风险暴露、精选成功人士、较低仓位、上市幸存者选择，都可能造成漂亮结果而没有额外预测优势。论文主多空alpha和延迟回归系数不能替代这个检验。

这里没有客户支付报价服务费：若将来做的是公开信号纯买入，利润依赖买入后的价格变化。复制的是信息筛选和时序纪律，不是XTX的机构客户网络、双边报价或自有执行体系。更强的语言模型不能补齐未知身份、未公开历史和没有支付记录的成本。

| 成交 | 普通交易时段、明确可解释的开盘/收盘价字段、保守披露后延迟 | 日柱标签或内部人士成交均价不是我们的可成交价格；不可映射则停止收益核算 |

| 对照 | 预先固定的直接持有基准、相同价格和成本假设；风险匹配方法只使用过去信息 | 收益不同但风险不匹配，记不可判定；不能事后调仓位直到对照好看 |

| 不确定性 | 预先确定最低可用事件量、相关事件处理、误差区间和主要检验，仅一个主口径 | 小样本或区间不足以区分零优势记证据不足，不升级为成功，也不推全方向必死 |

上表是经济证据门槛，不是已经完整冻结的实验协议。当前尚未给任何人的类别或交易信号，也没有足够证据核定真实费用、最低样本量、可执行成交价和风险匹配参数；这些不能借本页获得运行权限。

## 如何解释未来结果，而不移动门槛

- 扣费后赚钱，但不优于相近风险基准：只支持这段市场暴露获利，不支持额外预测优势。
- 表面优于基准，但风险、时钟、样本或成本不合格：不可判定，不能以漂亮收益放行。
- 合格且固定的样本外检验不支持增量：停止追加同定义的调参/择优实验；新的机制证据才是重开依据。
- 风险相近、样本外有稳健增量且成本压力仍通过：至多进入历史候选层；还需新的未触碰数据和真实执行证据。
- 缺数据或样本过少：停止受影响检验，保留UNKNOWN；数据获取失败不等于经济假设被证伪。

## 放大资金与财富目标

成交额、可用盘口/成交量、订单参与率、冲击随规模的变化和可用标的分散度，才能限制资金容量。当前只有有限披露原件与日价范围元数据，不能推算5000美元或几十万美元的可实现收益，更不能线性推到Gerko财富的1%。

规模增加可能提高单笔最低佣金的摊薄效率，也会增加冲击、集中度与同时可部署资金的约束；当前没有量化这些效应。即使小资金预测优势被证实，资本来源、持续年限、可扩容量、回撤生存和持续维护仍是独立缺口。没有资金、期限和完整净收益数据，不计算达到财富目标的年数或概率。
