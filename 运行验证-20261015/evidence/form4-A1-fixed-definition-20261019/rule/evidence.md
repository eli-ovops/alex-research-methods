# CMP Appendix A1：滚动三年分类的闭卷定义（不执行）

结论：A1可以冻结为“有完整连续三年合格交易则重算、否则保留旧状态”的分类逻辑。它与主文routine永久吸收态不同。本轮只定义一个当前三年窗口完整的子样本，不继承主文82bp、多空组合或净盈利结果。**身份键及合格交易的原实现仍有UNKNOWN；不是运行READY。**

## 1. 原文定位与已证规则

原件为已封存Harvard论文的`02-harvard.passive.txt`，SHA256 `1251a11d4d5bce3369d2057b04f7c95e9d1401a9a6717b7d993ce15cdf38e5ae`。以下行号按LF换行计数（`rg`/`nl`口径），不是将换页符也计行的`splitlines()`口径。

- L739–755：年初依据此前三个日历年的历史分类；每年都至少有一次交易才具首次资格。若存在一个相同月份在三个连续年均发生交易，则routine，否则为opportunistic。不是要求三个年份各自只有一次交易、不是每次交易都同月，也不是三年总计三笔即可。
- Table A1 L2990–3004：首次有连续三年交易窗口时分类；此后每年滚动重算，只要新窗口仍满足连续三年交易。若不满足，保留最近一次分类，直到再次满足。故A1可双向切换，不是主规则吸收态。

- L675–679：论文原始交易范围为公开市场买卖，排除行权及私人交易。普通股/合格交易的SEC代码与脚注映射本轮没有重新确证；不能仅凭P、取得A或持股增加自动认证合格买入。

买卖方向：上述首次资格和共同月份条件使用未按方向限定的“trade”。本定义将已确认合格的买和卖共同放入月份集合，再把随后交易的买/卖方向另存；不能擅改成“连续三年都是买入”筛选。原作者供应商层面对跨方向记录的合并细节未披露，保留该实现层UNKNOWN。

## 2. 唯一子样本取舍

原论文分类单元究竟仅按个人，还是按个人×发行人，仍为UNKNOWN。对同一全文作了最多四处有界补读：L548–567强调个人历史，L1780–1795讨论其在公司的年资，Table I L2474–2487按insider叙述，Table III L2556–2568又称insider交易某stock；这些不足以明确跨公司交易如何合并。不能靠常识补齐供应商身份键。

`(reporting_owner_CIK, issuer_CIK)`仅保留为**待选适配定义**，不是本轮已冻结原论文身份规则。它可避免用ticker或姓名替代实体，但也可能改变原信号。身份键未定之前，下述k只能指“未来具体方案明确并验收的分类单元”，不能实际分组或判任何人的类别；选择pair也不消除原规则忠实性缺口。联合申报不得把整份文件复制为每人独立成交。

设目标分类年为Y，历史交易日窗口为Y−3、Y−2、Y−1三个完整日历年。Y与身份键必须由后续具体方案明确，不能默用电脑当前年份。唯一范围取舍保持为“完整当前三年且每年有合格交易”的可重算子样本；只纳入同时满足以下条件的单元：

1. 有证据支持这三个年度的合格交易原件、身份关联及修订链在分类快照截止C_Y时已完整核对；目录有记录不等于该条件成立。
2. 三年每年合格交易数均大于零，且交易月份、方向及公开可见时钟没有影响判定的UNKNOWN。

当前完整但某年确无合格交易，和该年历史未核全，是两种不同原因；两者都不进入这个“可重算子样本”，不能标opportunistic。其他已有A1状态者在原规则中会继承旧状态，但本子样本一律排除这些需旧状态的单元。因此无需假装重建其终身状态，亦不声称覆盖整篇论文或全市场。

## 3. 判定逻辑（仅数学定义，不生成任何人的分类）

对纳入单元k，令M(k,j)为年度j内所有已确认合格交易的月份集合：

`eligible(k,Y) = complete_asof(k,Y−3:Y−1,C_Y) AND 每个M(k,j)非空`。

`common_months(k,Y) = M(k,Y−3) ∩ M(k,Y−2) ∩ M(k,Y−1)`。

eligible为真且交集非空→routine；eligible为真且交集为空→opportunistic。重复同月交易不增加资格；重复申报/4-A不能当额外交易。

完整A1状态机另有两条：eligible为假但有已证上次状态→保留该状态；eligible为假且从未有已证状态→UNKNOWN，不可首次分类。本子样本只使用eligible为真的分支，不把排除者改成第三种赚钱候选。

## 4. 分类可用时点与禁止回填

交易日tradeDate决定交易所属年份和月份；filingAvailableTime决定该交易当时能否进入已知历史。这两种时钟不能互换：晚披露的旧交易仍属旧交易月份，但此前不可被用来分类。论文年初分类不等于Y年1月1日已获悉前一年所有交易。分类只能在所需历史原件按实际可见时刻被核实且快照C_Y封存后用于后续披露。后续某笔交易也必须先公开可见；内部人士交易日、periodOfReport、签字日均不能替代外部人获悉时间。

若迟报/修订在C_Y以后出现，不得倒写原快照并声称旧时已知。如何处理后续修订、C_Y取值、时区差异和后续入场时点尚未冻结，保持UNKNOWN，不自行指定有利延迟、不生成信号或持仓。本定义不建立月度收益规则或交易订单。
