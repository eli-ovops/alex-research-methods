# 专用XGBoost：Tardis条款与输入字段

限定通过：当前条款文字支持个人本机内部的专用量化／统计模型研究；不等于数据已检验、实际交易可用或模型能赚钱。条款最后修改日为2026-09-13，本轮读取2026-10-17 UTC。

§9.5明确列出内部研究、策略开发、回测、交易执行、模拟和风险管理；不能自行增加“一律只准非生产”或“所有算法实盘另须书面许可”的限制。该解释以任务专用XGBoost属于统计模型为前提，并受§9.2、上游许可和§23限制。基础模型／通用AI的禁用路线仍保留。第三方模型服务及向外部服务方披露数据另有条件，本轮未证明满足，不向通用AI发送行情。

免费访问与许可分开：HTTP文档明确每月第一天无需key；条款§2说未另购付费服务的免费访问不收服务费。这不意味着连续整月免费，也未验证具体合约的保留历史和实际访问。§23对Coinbase另列限制，不能以供应商一般许可覆盖上游。

官方CSV schema确有UTC微秒双时间戳、best bid/ask及amount；exchange timestamp缺失时可用local timestamp回填。quotes由L2重建，book_ticker来自原生BBO；L2 amount为更新后绝对量，不是增量。重连快照、断线、空侧及处理后的交叉报价都影响对齐。价格／数量仍须按具体合约单位解释。

这些字段能支持新的短期微观结构预测问题；不能提供纳斯达克收盘拍卖专属字段和合成指数，也不能继承Optiver分数。标签只能用未来信息作事后答案，当前输入应按当时到达时间限制。本轮未计算标签、未请求行情、未运行模型。

唯一下一最小问题：一份事前固定合约／免费日，单位、覆盖和缺口是否足以定义连续60秒输入—标签片段。应先准备有界元数据／质量核验，不自行下载或运行。9次官方页面／范围读取、4次原生调用后已停网；第9次是首次仅取得身份后的schema正文补读。来源定位、逐条YES／NO／UNKNOWN及10项实际输入指纹见JSON。条款解释不是完整法律保证。
