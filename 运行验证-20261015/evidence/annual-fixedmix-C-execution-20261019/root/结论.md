# 年度配置C对照：动态目标的历史增量仍然存在

日期：2026-10-19。状态：**本次历史机制对照已执行并通过独立验收；A相对C有描述性的终值和回撤优势。** 这不是模型预测成功、真实盈利、容量或财富目标验收。原A/B的Sharpe增量0.20门槛和NOT_SUPPORTED结论不改。

## 这次到底比较了什么

共同窗口为2020-01-01 00:10 UTC至2025-12-31 00:10 UTC，2192个估值点/2191个持有区间。每种账户、每个费用档均以5000美元现金、零BTC起步，没有追加资金、利息、杠杆或做空。

- **A，动态年度目标：**已有封存规则，每年依据过去波动确定当年BTC目标比例，之后年内固定BTC单位与现金。
- **B，首次配置后持有：**已有封存对照，首次配置与A相同，其后保持单位与现金到终点。
- **C，固定比例年度再平衡：**本次新账；首次与A/B相同，此后每年恢复固定BTC比例`0.7853985165876642`，约78.54%，年内仍固定单位与现金。

仅新增C25/C50两账，A/B四账只读复用，没有重跑其策略。25bp和50bp分别是每边0.25%与0.50%的综合摩擦假设，按当笔参考名义金额计入首配、重配与末次清仓，费用影响后续本金。不是用户真实费率或真实冲击。

## 对赚钱机制的回答

这里的现金结果来自**持有BTC的价格变化与不同仓位路径，减去假设交易成本**。现金不计利息，没有客户或协议另付服务费，也没有本轮AI价格预测参与。

加入C之后，A仍高于C，说明在这个已见窗口里，A/B差距不能被“普通固定比例年度再平衡”完全解释；C也高于B，因此同样不能把A/B所有差额都归给动态目标。三条路径的账面比较不是唯一因果归因，也不是纯预测alpha。

## 验收与中途技术修正

- C两本完整账在评分前共同封存，再统一描述六账；独立检查实际读取六账共13152行，覆盖227200项核对，最大美元会计残差约`7.28e-11`。
- 同成本首配与2020全路径一致、C固定k/年度指令、自融资、费用、年界、预/后交易回撤、末次清仓及原件指纹均通过。真实窗口的计划调仓没有触发零量未成交；该分支由预运行合成用例与静态检查覆盖，不能冒称真实发生过。
- 第一次进程调用在建立市场计算锁前因Python3.9不识别尾Z时间格式而失败，未生成C账或表现。保留原失败，仅将同一截止时刻改为`+00:00`，新监督器只改输出文件名前缀；金融adapter、协议、数据和评分未变。
- 因此如实记录为**两次进程调用、一次入场前技术失败、一次实际市场账单元、两条新C路径**，不是两次策略试验。
- 入场失败、正式C命令和独立核验命令回执合计约0.863秒；实际市场worker与监督器抽样峰值约66.3MB。新增费用、数据下载、安装、模型运行、账户连接及交易均为0。独立核验没有生成新策略账户。

## 结论、限制与收口

**保留年度动态配置为历史研究候选。** 这次补充对照确实回答了一个机制问题，未被固定比例年度重配消除的历史差异仍存在。

仍不能将它称为已证个人赚钱方法：2020—2025已经被研究过，新独立市场样本为0；A/C敞口与风险路径不同，仍有选择效应；历史Close、正量即全量成交与固定比例费用是代理，首笔小额成交也未得到现实证明；A最大回撤仍超过56%。此结果不验证未来稳定性、真实可成交净收益、资金容量或Gerko财富1%的资本/所有权路径。
