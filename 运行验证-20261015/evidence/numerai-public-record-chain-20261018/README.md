# Numerai示例模型：公开记录链核验

结论：已实际取得官方示例的公共用户名／标识，但没有取得完整逐轮结算原账。该案例继续保持未通过净盈利准入；没有运行模型、回测、重新评分或交易。

## 这次实际取得什么

- 正常浏览器读到[NB_EXAMPLE_MODEL](https://numer.ai/nb_example_model)：页面“Woke”标注2019-11-01，当前说明写示例pkl自2023年末提交，Source Code指向移动master。两个时间标签和一个移动链接不能证明全期同一代码／权重；也不能据此断言它2023年换了模型。网页1年回报0.49%、全期137.5%均不能归因于已封存且可复制的固定模型，更不是已核美元净收益。
- 公开评分还列CORR60一年均值0.0045、MMC60一年均值-0.0005。前者衡量预测与目标的关系，后者衡量对平台模型组合的增量贡献；这里仅说明评价维度不同，不能用均值和当前倍率拼出历史奖励，也不能据此宣布永久没有优势。逐轮收益与费用原账仍缺。
- 按[官方NumerAPI客户端](https://numerapi.readthedocs.io/en/latest/_modules/numerapi/base_api.html)给出的免认证公共查询，成功返回`nb_example_model`及其标识。HTTP200、154字节，SHA256 `9a853292c9cbf51f7c30cac084d62b54e3c0e48b89a744a33336714736b02019`。接口返回`nmrStaked:null`，未当作0，也未用它覆盖网页0.05 NMR；字段映射仍待核。
- 一次公共`submissionScores`查询返回HTTP200、32字节、空数组，SHA256 `54694c3702fef24041c70106be8931f9d51dc19c7754e6ec56173af7b7d12242`。该请求同时使用`resolved:true`与`lastNRounds:1`，筛选顺序及最近轮次范围未核明；不能声称它选择到了“最近一轮已结束记录”。空结果可能来自筛选交集，但此原因也未证实，不能用它证明没有历史预测、没有收益或没有数据。

## 为什么仍不能说赚钱案例成立

官方客户端的当前`submission_scores`公共方法返回评分及版本／日期／提交标识，未包含逐轮实际质押、奖励销毁、交易哈希、链费与美元兑换成本。`pending_model_payouts`明确是认证用户自己的actual/pending结算方法；本轮没有请求它，不索取其他模型所有人的权限。旧v2公开方法虽列有payoutSettled字段，也不能把这个名称当作链上到账或完整费用证据；本轮未请求该旧方法。

完整历史代码、精确权重、原始预测文件、逐轮实际资金与全部成本仍未绑定。网页的百分比、文档中的方法、HTTP200、账户年龄、一个公共标识，分别都不能代替这一整条证据链。当前案例可学习预测评估机制，但不能升级为自有美股交易策略、稳定净利润、资金容量或Gerko财富1%的已验证路径。

## 传输与读取边界

首次系统Python urllib公共查询在响应前发生`TLSV1_ALERT_PROTOCOL_VERSION`；查询LOCAL_BLOCKERS后，现成curl8.7.1以默认证书校验（ssl_verify_result0）完成同一公共读取。未修复／关闭TLS，未改代理、认证或系统设置；`curl -q`不加载用户curl配置，没有导入NumerAPI、读取环境凭证或安装依赖。失败尝试与成功原件分别保留。

本轮按保守口径用完12次公开读取／观察／请求预算：Owner4份官方文档，root1次源码定向读取，4次浏览器观察，3次HTTP尝试（含首次TLS失败）。开始2026-10-18 07:43:03 UTC，完成与验收时间另列回执，20分钟内停止扩展。文档版本3.1.1，整体发布日期UNKNOWN；原生实际返回、来源范围与缺页见`client-source-read.json`及root补读JSON。浏览器字段见`profile-observation.json`，不是另存完整截图。

下一次如继续公共记录核验，已准备`next-public-read-spec-NOT-EXECUTED.json`：仅去掉未明确语义的最近一轮限制，按文档保留已结束及每轮去重条件，响应上限2MiB。它尚未执行；即使取得评分行，也不等于完整结算、费用、模型版本或盈利证明。不把这个读取草稿写成已开展实验，不请求登录、注册、质押或交易。
