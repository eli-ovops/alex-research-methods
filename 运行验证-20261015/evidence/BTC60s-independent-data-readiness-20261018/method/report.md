# 唯一方法对照：queue imbalance能支持什么

结论：**现有原件只支持“最优队列失衡与下一次中价变动方向有关”的可解释方法线索，不支持BTC固定60秒或费用净优势。** 最接近的是Gould–Bonart《Queue Imbalance as a One-Tick-Ahead Price Predictor in a Limit Order Book》。简单logistic是单个研究者可实现的机制基线；“低实现复杂度”是方法判断，不是个人可复制净利证据。目前没有同时满足本任务60秒、严格未来验证、执行费用完整的原方法证据。
