## 为什么现在不下载盘口继续算

既有四份条款／格式审阅已经由Owner复核，见 `existing-tardis-scope.json/md`。这是2026-10-17的来源审阅，不是本轮重核条款。它支持有条件的本机专用统计研究；向Codex等外部服务披露Data及DerivedData的条件未证实满足，Bitstamp专属上游适用仍待核。不能把免费获取当作通用复用许可，也不能泛称所有本机量化研究一概禁止。

CSV不含断线事件；原始HTTP回放文档才有空行断线标记。需要实际目标记录、初始快照及恢复记录才能核连续性。本轮仅取元数据，未取原始行情或示例CSV。Bitstamp WebSocket说明页本次网页读取没有正文，价格与数量单位仍标UNKNOWN；不重试防护、不换身份。

此外，六个元旦文件即使都可用，也缺12月31日退出成本；5/25档快照不是所有资金规模的完整深度，更不是实际成交回执。旧账的收盘价全量成交假设、25/50bps假设、2020诊断的NOT_SUPPORTED_THIS_DIAGNOSTIC结论均保持不变。
