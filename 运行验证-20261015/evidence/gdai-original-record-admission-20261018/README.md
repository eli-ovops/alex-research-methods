# gDAI：收入机制与原账入口筛查

截至 2026-10-18。本轮仅研究公开资料；未运行模型、回测、收益重算、链上调用、账户操作或交易。

## 结论

**只保留为研究样本，未接纳为已证实扣费盈利、可复制的案例。** 收入机制已得到官方文本支持，也定位到官方列示的 Arbitrum gDAI 地址；尚未取得绑定具体历史版本、参与者和期间的完整原账。没有证明净盈利、风险可比优势或资金容量。

这次研究从“预测价格”转向“谁支付收入”：gDAI 提供交易对手资金，换取部分交易手续费，同时承担交易者获利导致的赔付风险。这有助于理解流动性生意；它不是 XTX 私有预测模型的复现，也不是普通个人已取得预测优势的证据。

## 已证实的官方披露

1. gDAI 是代表 DAI 资产的份额。相关金库承担以相应抵押资产交易的盈亏：交易者获利由金库支付，亏损流入金库；金库分得部分交易费。DAI 计价不等于美元保本。
2. 官方份额兑资产公式是 `1 + accRewardsPerToken - max(0, accPnlPerTokenUsed)`。交易者净亏损先形成超额抵押缓冲；缓冲高于 100% 的部分不直接增加份额价格。不能将“所有客户亏损”直接等同持有人利润。
3. 盈亏采用周期快照；赎回需要请求及指定窗口内执行，不能随时立即退出。手续费增加不保证最终净收益为正。
4. FAQ 的 Estimated Earnings 将转入转出按当时估值视为存取或交换。它不是实际成交价、到账额或全费用原账；其 25 DAI 数字为官方教学示例，非真实账户盈利。
5. 官方地址页列出 Arbitrum gDAI：`0xd85E038593d7A098614721EaE955EC2022B9B91B`。本轮未读取浏览器上的验证实现、升级历史或交易明细。官方技术参考是函数说明，不能当作已经核验的部署源码或许可。

## 个人能借鉴什么

- 可以学习：收入支付方识别、手续费与风险赔付分开记账、存入和赎回的现金流核验。
- 不能仅靠更强预测模型获得：有付费交易需求的交易平台、对手资金、风控和结算机制。这是不同商业环节。
- 是否能低成本参与该具体金库尚未确认：地区资格、适用条款、可执行成本和真实风险未核全。本报告不建议入金或连接钱包。
- 费用与风险待核：实际链上交易费、换币和跨链成本、平台费用及税务口径、DAI 脱锚、合约/预言机/升级和退出窗口风险。其中风险分类属机制推断，不是已发生损失或精确概率。
