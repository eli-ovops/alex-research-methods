# 免费数据通道：独立最小核验方案审阅

**结论：文档足以准备一次 HTTP 优先的最小功能/一致性检查方案，尚未证明通道已可用，更未证明机会捕获或盈利。本轮不开发、不注册、不配置 key、不发链请求。** 真正需要人类介入的是账户建立/条款接受与 key 仅在本机配置；不因操作叫 RPC 就另造一般公开只读数据获取的审批门槛。当前 protocol 明确不发请求的范围仍遵守。

## 依据与实际缺口

- `methods-owner/report.md` 全文及 receipt：官方 `eth_call` 页列固定 block number/hash 字符串；未证 EIP-1898 对象和 `requireCanonical`，也未证 batch 或同一连接具有原子快照。WebSocket 可能重组、重复、静默失败；普通请求建议 HTTP，不能把块时间当本机接收时间。本文不以缺对象支持否定所有固定区块读取。
- `01-pricing.text.txt` 第 127–136、303–338 行：Free 标示每月 30M CU、300 CU/s（页面括注 15 requests/s）、5 apps。RPS 与 CU 不是可互换保证。`03-billing.text.txt` 第 6–11 行：加卡或升级立即转 PAYG，PAYG 无底层免费额度；WS 通知亦消耗 CU，不包含在普通请求计数中。第 23 行说明事后设上限不能撤销已产生费用。`05-billing-model.text.txt` 是一般付费累进账单说明，不是无卡注册承诺，不将其账单门槛套成 Free 收费。
- `04-legal-index.text.txt` 当前 TOS 2.0（2025-06-27）§2.1、2.2、2.3、2.6、2.11：在 Licensed Volume 内有条件内部用途许可；授权接口使用与抓取、转售、绕量、共享 key 或竞争性服务基准评测不同。免费档按现状提供、可停用；不能由通用 SLA 推成 Free 有时效保证。对这次内部功能检查，未见必须先取得额外书面许可的条款依据；也不把此有限解读推广为任意数据再分发或所有用途授权。

**尚未就绪的不只有“有没有 key”：** 实际账户的 Free/未加卡/未升级状态、剩余额度、最终注册是否要求卡、精确方法 CU 及固定调用参数/ABI 身份还需准备时核实。无卡承诺未核不等于已证必须付费；方法 CU 未核也不应靠请求数伪造零费用保证。这些是具体准备项，不是整体赚钱障碍或新模型 Gate。当前没有足以要求重新全局条款审查的明确冲突。

## 建议冻结的唯一主检查（尚未执行）

只选 Ethereum、一个用户账户/应用、一个官方 HTTPS endpoint。用户仅在本机完成免费账户与 key 配置；报告不含 key、带 key 的 URL、请求鉴权头或凭证值。准备时确认实际仍为 Free、未加卡/未升级且有可用额度；界面要求卡、付费或套餐状态不明即停，不尝试用设事后 spending cap 代替免费状态。

**总额 0；单进程/无并发；最多 8 个 HTTP JSON-RPC 请求，最多 60 秒，每请求至少间隔 1 秒；单体响应 128 KiB、总响应 1 MiB；不自动重试、换 endpoint 或放宽参数。** 这是建议的工程预算，不是已测性能或已算 CU。执行准备须将精确请求、来源 ABI/方法参数、响应大小与停止规则封存，且确认这些固定方法适用于账户额度；不需要先计算仓位资格或收入。

1. 一次 `eth_chainId`；一次读取 `finalized` 区块头，取得固定 `B/H`。实际区块方法 schema/标签在准备时确认；不支持、为空或错误则停，不临时退到 `latest` 或改确认深度。
2. 对数值区块 `B` 读前置区块头；然后对两个事先固定的公开 view getter，各读两次且全部显式指定 `B`。可选既有已核 WETH Registry 的 `MCR()` 与 TM 的 `getTroveIdsCount()`，地址/部署/ABI 先绑定；这不是仓位扫描、ICR 资格判断或补偿计算。不用 `estimateGas`、trace、账户签名或广播；`eth_call` 只读调用的 gas 上限和空 value 在准备时固定，不让任意 calldata 入场。
3. 最后再读 `B` 区块头，核前后 number/hash 与初始 `B/H` 相同；两次相同 getter 原返回值相同。没有证明 hash 对象支持前，不改用未核对象。前后 hash 和重复值吻合只叫“本次观测的固定标识/返回一致性通过”，不叫多请求原子快照、独立节点认证或不会重组。

主检查**不含 WS**，最小功能检查不需要它。未来若确有单独目的，再事前限定一个订阅、短时长、消息/字节/CU 预算及既有依赖；只作通知观察，无消息不能填成零机会或可靠性失败，不把 reconnect/backfill 当提供者保证。不得临时订阅所有日志或做长期监听。

## 通过、停止及 UNKNOWN

通过仅限：身份正确、固定请求被接受、返回结构合法、上述 `B/H` 与重复 getter 检查一致、在预算内完成。即使通过也不认证当前清算机会、历史可用性、全字段够用、实时延迟/通知完整性、抢先执行、成功率、净利、容量或财富目标。

401/403/明确拒绝、429、付款/升级要求、额度或条款冲突、超时/超预算、空/非法响应、区块身份改变或返回不一致即停止并保留。拒绝不换身份或路径；链重组与 provider 数据错误在原因不明时分开记 UNKNOWN，不把单次失败升级为所有免费服务不可用。程序正常结束本身不能编码上述一致性通过。

**集中 must_fix：当前无。** 若后续正文把 Free 宣传写成已验无卡账户、把 15 RPS 当方法 CU 保证、把默认 latest 或前后 hash 检查写成原子快照、把条款可用性写成实测盈利，应修正。当前可交付方案，不能借此在本轮临时执行。
