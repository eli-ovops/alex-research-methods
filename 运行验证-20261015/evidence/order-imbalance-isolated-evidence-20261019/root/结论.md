# 挂单压力：隔离增量与成交筛选的收口核查

决定：维持停止追加单一顶层挂单压力/60秒主动交易候选实验。新增证据削弱“改用便宜挂单即可兑现预测”的补救理由，但不是我们未运行的固定60秒候选的直接阴性结果，也不否定所有此类信息。

§2：作者报告2024年2月与8月的真实最小规模挂单采集实验；§6利用采集到的订单结果分析策略，不是我们新执行或完整独立核账的实盘策略。使用有利费率、忽略延迟等假设。

§6表2给出的平均每往返扣费结果（基点，非账户ROI）：

|策略|作者报告均值bp|
|---|---:|
|按失衡主动成交|−1.9621|
|按失衡挂单、不额外撤单|−0.4705|
|按失衡挂单、失衡反转时撤单|−0.4921|

机制：有利方向下在长队尾部的挂单可能错过有利行情；实际成交的子样本承受不利选择，不能把全体报价的预测能力直接作为成交后收益。主动交易则受双边费用限制。该研究的日期、市场、持仓周期和策略均不同于我们的固定60秒实验，不直接替代本地检验。

作者另有多特征反转研究；当前用户限定只拆挂单压力，未将它启动为新策略、未调模型或运行其结果。
