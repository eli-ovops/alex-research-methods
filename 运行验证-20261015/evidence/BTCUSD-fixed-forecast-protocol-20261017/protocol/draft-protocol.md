# BTC/USD 60秒预测检验提案 v1.0（未执行）

本提案只检验一个问题：当时已到达采集器的最优报价和数量失衡，能否让专用 XGBoost 对未来60秒中间价变化的预测，超过不变价格及同特征 Ridge。它不是交易策略、Optiver 分数复现或 XTX 私人模型。本轮行情获取、代码实现、训练、推理、回测和交易均为0。

## 固定数据与时点

34个候选日期为每月1日：2024年12天训练；2025年1—3月3天验证；2025年4月—2026年7月16天旧接口测试；2026年8—10月3天新接口测试，9月1日保留。它们只是日历清单，尚未取得任何日文件。2026年7月10日采集接口及标识切换，须先核两版字段语义可比；无法建立共同含义就记数据不足，不换年代或日期。

每天只研究 UTC 12:00—14:00。这是控制原始连续性核验成本的事前取舍，未搜索最佳时段，结论不能推广到全天。quotes CSV 仍须取整日压缩文件；不能 HEAD/Range 取几行。另计划同符号 book 原始流11:50—14:00的13个十分钟片段，34天共442个，加34份 CSV 共476次数据 GET，未来总上限500次。实际大小、覆盖、用途适用均未完成核验。

以 `local_timestamp` 决定信息到达；不把交易所事件时间排序到更早。每个时点只用已到达的最后一条有效 BBO。同本地时间按原始行序，不插值、不向未来找最近行。价格/数量须有限且正、双边齐全、ask>bid。local 时间回退作为质量错误保留，不静默修复。

有效特征及标签检查点要求 quote-age≤5秒。这是限定“新鲜报价”适用域，并非把长时间不更新的正常 BBO 宣判失效。quotes 只有 BBO 变化才产生记录；空分钟或无新行都不能证明断线或市场无事件。

直接使用供应商标准化、从 L2 重建的 quotes，不额外要求每个前缀均有原始快照。原始流用于断线与恢复资格：前缀无快照而无观察到断线时，可在明确供应商重建及更早历史未知的假设下用 quotes，不能声称前缀证明完整状态。观察到断线后暂停，直到原始完整快照及随后有效标准化 BBO；窗内未恢复则余段不纳入。缺失应取的 raw 片段使该日连续性未知，不等于零活动。不扩取更早前缀。

## 唯一标签、特征和模型

标签为 `10000×ln(mid(t+60s)/mid(t))`，单位是对数收益基点，不是 WAP 相对合成指数或投资收益。训练每10秒取一点；验证及测试每60秒取一点；均在12:01≤t<13:59。最多分别708/118点，排除无效数据后只在同一合格连续段取样。信息支持为[t−60,t+60]；边界净化并留120秒 embargo，不做随机折叠。测试未来区间不重叠仍不等于样本独立。

六个特征固定为：当前数量失衡 `(Qb−Qa)/(Qb+Qa)`、相对价差基点、10秒失衡变化、过去10个每秒因果失衡均值、过去10秒和60秒中间价对数变化。绝对历史数量单位未证不等于全部失衡不可用，但须确认同一快照两侧共用单位；不使用未证的美元名义数量。训练期均值/标准差处理两模型同一六特征，零方差映射为0，不用全日/测试中位数，不补未来信息。

固定 XGBoost **3.0.5**：CPU、hist、300树、深度3、学习率0.03、min_child_weight20、lambda10、alpha/gamma0、max_bin256、全行全列、base_score0、seed20261017、6线程、平方损失。Ridge **scikit-learn1.6.1**，alpha1、含截距、SVD；第三个基准预测0。每个训练日权重相等，两模型相同。只在2024合格训练日各拟合一次，无调参、早停、重训或集成。验证只作固定方案运行质量检查，不据此换配置；版本是未来提议，不是已安装回执。确切代码/依赖哈希须在未来测试暴露前冻结。

## 判输赢与数据不足

每日至少95/118个评估点合格，训练日另须567/708点；合格日最少训练10/12、验证3/3、旧测试12/16、新测试3/3。所有34日及排除原因保留，无替换。质量资格先于损失检查；这些过滤会限制适用域。

主要分数是逐日 MSE 后等权平均，单位基点平方，MAE只描述。旧测试对零及 Ridge **各**至少降低1%，且各自逐日成簇、10000次固定种子 bootstrap 的单侧97.5%下界>0；两个比较按 Bonferroni 控制。不能把重叠行当独立观测。基准误差为0时相等只算持平。

新版3天对两个基准均须平均有正改进，且每个比较至少2/3天改进；单独列出，不用混合置信区间遮盖迁移失败。即使全部通过也只是固定域内预测候选证据，三天不足以证明当前新版稳健显著优势。旧期通过而新版失败，明确本提案迁移证据不通过。

四种结果：有限预测候选通过、固定假设不通过、数据/可比性不足、资源停止。未解决实现错误属于无有效实验，不作模型失败；若测试后发现错误，保留失效结果，新版本不得伪装未见测试。

## 预算、许可和盈利边界

未来预算新增付款0、6线程、8GiB内存、含下载解析训练评分总4小时、总压缩8GiB、单CSV512MiB、单raw片段64MiB、解压及临时24GiB、总峰值磁盘32GiB。它们是停止上限，不是文件大小/必能完成的预测。未知长度也按接收字节限额；中止文件不当完整证据，不自动续传、扩期或加预算。

Tardis 专用统计例外与 Kraken 数据经 Tardis 接收后此项离线用途的具体上游适用分开，后者仍 UNKNOWN；不能因一般保留句额外要求一律授权信，也不能据无 key 自动许可。§9.5还单独限制向外部服务提供方披露 Data、Manipulated Data、Derived Data，涉及书面用途限制及 Supplier 执行权；本 Codex/LLM 流程未证满足。原行情、特征、预测以及派生误差/收益汇总留在合格本地边界，不能以“不传raw、只传汇总”自动放行。若未来复核需这些材料，当前该复核路径仍未就绪，不承诺把结果交通用AI审阅。不因本提案保存而授权获取或执行。

误差增量不是赚钱证据。后续若另行研究盈利，须用真实可执行价、延迟、价差、费率、滑点/冲击、规模、融资与库存风险、实际成交依据和回撤；不假定 maker 排队成交。本提案不运行这类检验，不推容量或财富目标。唯一下一问题是固定34天、双版本、连续性输入在许可及资源条件下能否实际取得并一致归一；当前只列条件，不自行取数。

## 原始依据的限度

Cont/Kukanov/Stoikov 摘要谈美股短区间订单流与价格关系；Gould/Bonart 摘要谈美股下一 tick。它们仅支持研究动机，**未证明 BTC 的60秒增量**。60秒为此次固定新假设。参数定义来自 XGBoost3.0.5 和 Ridge1.6.1 官方正文，参数数值及1%门槛等均是本提案选择，非论文推荐或已获结果。
