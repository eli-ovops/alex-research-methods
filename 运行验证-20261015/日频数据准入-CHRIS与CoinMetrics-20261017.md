# 日频数据准入：CHRIS与Coin Metrics

核验日期2026-10-17。总体目标仍是合法复制可赚钱的环节，并判断是否能扩展至Gerko财富1%的量级；目前目标未完成，本轮没有模型、训练、预测、回测、交易或付款。只实际取得Coin Metrics的5行历史样本作字段/访问核验，没有下载全历史或权重。

**结论：技术上找到了免费匿名价格接口；用于本项目盈利目标的数据准入仍未完成。** 不能将“个人研究”自动改写为“非商业”，也不能用访问成功代替许可。另在公开作者下载器中发现条件性数据混用风险，已由独立审阅者确认逻辑；尚无实际发生证据。

Coin Metrics的[官方数据许可](https://github.com/coinmetrics/data/blob/f1a36afb962731c387bb03982758ab0103063da5/LICENSE)明确非商业。其官方Community API说明另行明确无需key、非商业CC许可及10请求/6秒/IP限额，并非从代码许可推断数据权利。[CC法律原文](https://creativecommons.org/licenses/by-nc/4.0/legalcode.en)以主要目的是否指向商业利益/金钱报酬界定NonCommercial。个人、本机和尚未交易不能自动解决本项目适用问题；本报告也不宣称所有个人研究违法或一律需要额外授权信。仓库观察commit为2026-05-24，实际访问与许可读取发生于2026-10-17。

PriceUSD是美元参考价，非单一交易所可成交价。官方定义其日频值为UTC日终价格；00时日期标签不能当该时刻已知值。精确发布延迟、历史首次可取得时间、修订和全历史缺失重复仍未核。五行也不能证明全历史质量或未来数据持续可用。若之后进行任何研究，必须先处理真实可用时点；不能因而改动旧封存测试。

该数据与多资产期货结算价不同，即使将来获准使用，也只能做独立假设检验，不能声称复制原论文收益。API terms链接重定向到产品首页不等于附加条款消失；API数值、仓库数据和SDK/软件许可分别核对。

公开作者下载器还有一条会影响数据可信度的静态路径。[固定源码](https://github.com/kieranjwood/trading-momentum-transformer/blob/e0352cb0bdbf8045accb1bf1a5705ae0cb9ea624/data/download_quandl_data.py#L18)在请求失败后只打印异常，没有跳过保存或清空data。首次失败可能访问未绑定变量；先成功后失败，若保留数据仍满足字段/日期条件且写入成功，可能把上一品种数据写为当前品种文件。这是有源码支持的条件性失效路径，没有运行模拟、没有证明历史下载发生过，更不能用来解释旧BTC模型或认定论文原始数据错误。未来若采用该下载器，须先解决失败处理并验证每个品种身份，不能直接信任生成的文件名。

当前可低成本借鉴的是许可证与字段核验、按真实信息时点组织数据、下载失败即停止，以及品种/快照身份检查。它们防止错误实验，本身不产生交易优势。模型优势、全成本净利、回撤、容量和财富积累路径仍缺实证。

唯一下一步：只读核交易所第一方公开历史数据（先核Binance Public Data）的具体授权，确认是否覆盖个人内部、以盈利为目标的预测研究；同时区分数据与软件许可。未得到证据前不自动采用、不取整段数据、不运行模型，也不通过重命名研究目的绕开NC限制。若需要新增付费或账户权限，再向用户提出具体事项。
