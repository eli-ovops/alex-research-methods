# Kronos-small 首轮真实离线评估

执行与读取日期：2026-10-15（北京时间）。本报告记录一次实际运行，未连接账户、下单、训练或付费。用户已明确允许在核清研究数据使用依据后，做一次固定方案的本机离线评估。财富目标仍在进行中，尚未取得盈利或可放大资金规模的证据。

**结论：本次固定用法未通过预测门槛。188个窗口中，Kronos-small的均方误差比“未来收益为零”的基准高4.18%；优势的95%统计区间跨0，没有证明它更优，也没有证明它显著更差。** 本次是AAPL（苹果股票）补充检验，不是BTC检验，也不是作者股票实验的完整复现。

## 测了什么

开始预测前已保存[固定协议](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/protocol.json>)。没有根据结果更改资产、时间段、参数、随机种子或评价指标。

| 项目 | 实际设置与范围 |
|---|---|
| 数据 | Twelve Data官方发布的Financial World Model数据集，固定版本的 `bars_1h/test.parquet`，只选AAPL |
| 为什么用美股 | 该官方数据发布具有本次私人研究的正面许可依据；采用它不代表Bitstamp许可缺口已解决 |
| 全部AAPL记录 | 2025-01-02至2026-10-13，共3113根；2025-07-01起共2259根 |
| 评价目标期间 | 2025-07-01 09:30至2026-10-13 12:30，America/New_York时区 |
| 输入 | 每次80根已完成交易时段价格柱，仅开盘、最高、最低、收盘四个价格字段（OHLC） |
| 缺少的输入 | 未提供成交量与成交金额；官方预测器按其缺省路径填0。未输入复权收盘价、宏观变量或其他指标 |
| 输出与评分 | 预测未来12根交易时段价格柱，取第12根预测收盘价相对最后已知收盘价的收益，和实际终点收益比较 |
| 窗口 | 每12根向前推进一次，188个窗口的目标不重叠；相邻历史输入仍有重叠 |
| 抽样 | 每个窗口10条抽样路径，T=0.6、top_p=0.9、top_k=0，固定种子20261015+窗口编号 |
| 本机资源 | 16GiB内存的Apple arm64电脑，CPU 6线程；全程推理合计约205秒，不含下载、环境准备和审查 |
| 费用 | 新增付款0；环境、缓存、数据和权重保留在外置工作目录 |

“12根交易小时柱”不等于12个自然小时：休市不计入，正常交易日最后一根可能只有30分钟。本次按交易所日历产生未来时间戳，没有把未来价格传入预测器。详情见[质量检查](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/results/qc.json>)与[运行元数据](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/results/metadata.json>)。

## 真实结果及其含义

均方误差（MSE）是预测收益与实际收益之差平方后的平均值，越低越好。“零收益基准”表示始终预测未来价格等于最后已知价格，不代表持有现金的实际投资表现。

| 事先固定的指标 | 实测 |
|---|---:|
| 零收益基准MSE | 0.0005190388971 |
| Kronos-small MSE | 0.0005407331397 |
| 模型误差相对基准 | 高4.1797% |
| 平均优势d＝基准平方误差－模型平方误差 | −0.0000216942426 |
| d的95%时间区块重抽样区间 | [−0.0000496789579，+0.0000039611713] |
| 按时间分成前后两半的平均d | −0.0000219627038；−0.0000214257813 |
| 预先固定的通过条件 | 区间下界大于0，且前后两半平均d均大于0 |
| 判定 | **未通过** |

时间区块重抽样指按连续一段窗口抽取样本，以保留部分时间依赖；本次块长10、重复5000次。区间依赖这一假设，188个窗口也不等于188次完全独立试验。方向一致率52.13%只是描述性读数，没有据此更换通过标准或声称盈利。[原始汇总](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/results/summary.json>)

从第一性原理看，我们要找的是“当时可知的信息，使未来判断持续优于相应基准，再转化为扣成本后的净收益”。这次已经证明个人可以低成本完成固定权重的真实预测与核验；尚未证明此用法包含可交易的增量信息。漂亮的预测图、模型顺利运行、方向命中率略超一半，都不能替代后者。

## 防止信息泄漏，仍有哪些边界

1. **时间边界。**固定small权重的上传提交记录为2025-06-30，所有评价目标从2025-07-01开始，早于目标的历史输入可以使用。下载后的权重哈希与固定版本LFS记录一致。该时间排序缓解训练样本与目标重叠的担忧，但不等于作者披露了完整训练截止日期、训练清单或清洗流程。[固定权重版本](https://huggingface.co/NeoQuasar/Kronos-small/tree/ac5c409a313c4eadd1ca78201322f5cadb9c34ab)
2. **回顾性检验。**这次在2026-10-15读取历史数据再预测，不是事先封存预测、等待未来行情产生的前瞻验证。未独立重建供应商每个历史时点的数据修订状态；没有把数据集文件名“test”当成对所有模型都有效的样本外证明。
3. **输入与对象边界。**作者股票设置含价格、成交量、成交金额（OHLCVA）。本次四价格字段、其余填0的股票探针不等于该完整设置；不能把当前失败推广到完整输入、所有资产、所有周期或所有AI模型。没有量额对照实验，不能把失败归因于缺少量额，也不能假定补上就能改善。模型训练时各市场的时区规范也未完整核清。原BTC方案仍未运行。[固定源码](https://github.com/shiyu-coder/Kronos/tree/67b630e67f6a18c9e9be918d9b4337c960db1e9a)、[作者论文v1](https://arxiv.org/html/2508.02739v1)
4. **盈利边界。**MSE改善既不是所有盈利策略的必要条件，也不是充分条件。本次没有定义交易决策、模拟成交或测试费用、滑点、未成交、回撤与容量，因此不能计算策略收益或声称“加上费用一定亏损”。
5. **重复试验边界。**这188个窗口已用于评价，不能再用它们反复调整输入、缩放、阈值、周期或选股，然后称调整后结果是新的独立证明。后续改法应单独冻结，并使用未用于选型的留出数据或新发生数据，记录试验次数。

## 对赚钱与放大的判断

**当前不支持把这套固定预测直接作为投资立项或加资金、加算力的依据。** 这不排除继续做有限方法研究，也不等于AI预测整体不可行。现在得到的是一个需要保留的负向结果，不能靠换指标将它写成成功。

| 目标环节 | 当前证据 | 缺少它的后果 |
|---|---|---|
| 个人本机运行公开预测模型 | 已实际完成 | 运行门槛已解决，但不构成竞争优势 |
| 当前用法存在稳定预测增量 | 本次未证明 | 没有可靠理由把输出转换为资本投入 |
| 净赚钱 | UNKNOWN：未测试 | 缺可执行规则与真实成本账，不能报收益率 |
| 放大至几十万美元或更高 | UNKNOWN：未测试 | 缺成交冲击、退出、机会数量和风险资料，不能报容量 |
| 达到Gerko财富1% | 尚无已证明路径 | 还缺可持续净优势、容量、资本来源、风险承受及税后留存；估值不等于现金 |

唯一建议的后续研究问题是：**与作者股票输入规范相比，缺失成交量、成交金额及时间规范会怎样改变这个测试的有效性？**先作输入一致性审查，再判断是否值得另冻结一次完整输入评估。它的验收是找到官方规范、真实可用字段和未用于选型的独立数据安排，而不是在已看过的188个窗口里调出漂亮成绩。本次没有自动启动第二轮、微调、参数搜索或交易试验。
