# Aave公开利息案例：首十笔筛查与证据边界

读取与核验：2026-10-16；这是公开历史资料研究，不是模型试验、回测或交易。

本轮没有找到满足预设全部条件的盈利案例。核清的是Aave V3 Ethereum USDC的计息、提款和分账机制，以及固定顺序十个实际提款账户为什么不能纳入本轮简单现金流样本。十个被排除不代表十个亏损，更不代表Aave不能产生利息。没有计算、排序或筛选它们的净收益。

## 1. 它凭什么收钱，谁付钱

存款者把USDC提供给借贷池；借款者为使用资金承担利息。协议按市场利用率及治理参数更新利率，用累计指数把存款者应得的利息计入其aToken余额。aToken是可转让的计息债权凭证，因此接收别人的aToken也会获得提款权，不能只看提款认定本人赚了利息。[Aave V3借贷池说明](https://aave.com/docs/aave-v3/concepts/liquidity-pool)、[aToken说明](https://www.aave.com/docs/aave-v3/smart-contracts/tokenization)；两文发布日期UNKNOWN，本轮读取2026-10-16。

简化资金逻辑：

```text
存款者提供USDC → 借贷池提供资金 → 借款者承担利息
                                      ↓
                      债息的一部分记入协议储备
                      存款者按流动性指数累计利息
                                      ↓
                    提款时由池内可用USDC实际兑付
                    存款者另付以ETH计价的链上费用
```

这是资金使用费的分配机制。应计利息、借款者实际还款、协议储备和某一存款者实际收到的USDC是不同口径；不能说每笔提款都直接来自某个借款人的当笔还息。提款还受池内未借出流动性等限制。[Aave V3 Pool](https://www.aave.com/docs/aave-v3/smart-contracts/pool)。

本轮取得提供商声明的Pool与aToken已验证源码、ABI及升级事件：提款周对应Pool实现为`0x728a138a4823392c2efa55e028d434f526fe03cf`，aToken实现为`0xadc45df3cf1584624c97338bef33363bf5b97ada`。源码显示MaxUint提款销毁用户全部scaled余额并转出换算后的底层币；Mint/Burn事件可能包含累计利息，不能把事件值直接当作现金流。ReserveLogic能证明储备分账路径，不能证明当时具体reserve factor、完整利率参数或APY。

实现声明和事件来自单一公开索引器，未独立编译比对字节码。最早公开日期未核；不能以今天读到源码声称该精确版本在投资者入场前已公开。较早Supply还可能跨越2026-05-29升级，不能一律套用提款时版本。

## 2. 选例规则在检查收益前固定

原始选例文件：[actual-case-selection-before-cashflow.json](evidence/aave-usdc-cashflow-baseline-20261016/root/actual-case-selection-before-cashflow.json)，SHA-256：`c992101ce243e761c5418b5fe9c0a42e4d33d0dfedce90d6398adc49d0aa164c`。

- 时间：UTC 2026-09-01 00:00至09-08 00:00，不含结束端点。
- 对象：Ethereum Aave V3、USDC；按区块和全局日志序号取最早十个本人直接成功调用MaxUint全额提款的候选。
- 简单账条件：本人自付的一笔USDC Supply、一笔最终Withdraw，无第三方aToken来源或借款杠杆；本金500—20,000 USDC，持有7—180天；凭底层币实际转账与成功收据核输入输出，费用包括相关审批和直接失败交易。
- 首个合格案例无论正负都保留；最多检查这十个，不因未找到正收益扩大日期、改门槛或挑后面的赢家。

这是本地、事后历史研究的选例约束，不是独立公开预注册，更不是预先公布的真实投资决策。

## 3. 实际查到什么

USDC Withdraw日志正常分页返回`1000/1000/1000/1000/1000/166/0`，共5,166条，事件键无重复。29条transactionIndex字段为`0x`，保留原件，排序只用block/global logIndex。另取Pool交易的升序1,000条前缀，返回17个符合直接本人MaxUint形式的交易，前十个均早于页尾。

这些完整性和顺序结论限于该提供商返回集合。没有独立证明全链无漏，也没有把1,000条交易前缀写成全周交易全集；对有正面排除证据的候选只读取足够排除的历史，不称已核完其全部账户账本。

## 4. 个人能复制什么，还缺什么

能借鉴的是公开规则核验、利息归属核验、逐笔现金流和成本核算；在机制层面可研究已有协议的资金供给服务，无需私有价格预测模型或机构客户。它的收入来源是资金使用费，不是已经证明的预测超额优势。

仍缺三层证据：

1. 一份完整、可绑定的实际本金、提款、持仓变化及全部适用费用账，证明某个明确期间扣费后结果。
2. 事前公开的资产选择、存取时点和风险约束；协议计息规则公开不能代替投资者完整操作规则事前公开。
3. 个人适用性、跨时期可持续性和规模证据。利率会随供需、治理和规模改变，不能从一笔正息线性外推到几十万美元、容量上限或Gerko财富1%。

官方2026-08-31治理论坛材料明确建议调整USDC等参数，说明规则参数会变化；这是提议，未核执行，不能把建议值当本例实际值。[原讨论](https://governance.aave.com/t/risk-stewards-cap-and-irm-changes-on-aave-v3-2026-08-31/25571)，发布2026-08-31、读取2026-10-16。

公开可读不等于可以任意复制全部代码。固定地址簿许可给予MIT式使用权；所读实现主要文件标BUSL-1.1、部分MIT，完整附加授权/变更日期未核，不能说整个实现可无限制商业fork。Aave Labs条款另列服务使用资格、地区限制、费用及风险；协议、前端、数据服务和代码许可要分别核。本轮没有确认用户未来交易的法律或服务使用资格。[条款](https://aave.com/terms-of-service)更新2026-09-07、读取2026-10-16；它不是本例较早入场日条款的历史快照。

缺少成本控制，少量利息可能被审批、存取或失败交易费用吃掉；缺少余额来源核验，会把别人转来的本金算成收入；缺少风险约束，则仍承担合约、治理、流动性和USDC资产风险。以上是机制风险，不是本轮已发生损失的断言。

## 5. 本阶段判断与下一项

本轮属于实质证据推进，但尚未满足用户要求的完整扣费盈利案例，更未达到个人赚钱或财富目标。Aave暂保留为公开现金流基准，不能升级为可复制赚钱结论。

下一项只研究已入选十个中的第2笔：它是固定顺序最早出现、从首轮日志看一存一取且本人自付的候选，目的改为核清短周期的小额利息能否覆盖实际费用。保留它不符合原本金/持有期门槛的结论，不以它补作原样本通过，不寻找新地址或日期。选择时本金与时长已知，提款原日志已取得，但收益未解算；不是重新的前瞻试验。

该账核验须包括真实USDC进出、aToken是否另有来源、成功/失败及相关审批gas，ETH费用先单列；如换算成本，必须先固定同时点报价来源与规则，并标为估值而非实际结汇。无论正负均保留。它可回答成本问题，不能单独证明稳定盈利、预测优势或容量。
