# 预测市场套利复制条件：完整组合可提前合并，费用与成交仍决定结果

核验日期：2026年10月16日。范围仍为免费公开原件研究；未运行模型、回测、SQL、第三方源码、SDK或EVM，未登录、注册、安装、付款、下单或修改自动化。

## 1．先给判断

**完整二元组合不必一概等到事件揭晓，才有取回抵押物的路径。** 当前官方文档明确区分：完整、等量的YES/NO可以合并；只有单边获胜权利的兑付才依赖市场已解决。它缩短了一个可能的资金占用环节，但不证明能买到便宜且配齐的组合。[官方持仓说明](https://docs.polymarket.com/concepts/positions-tokens)、[官方合并操作](https://docs.polymarket.com/trading/positions/manage)

**旧论文的费用假设不能沿用到今天。** 当前官方披露部分市场向主动成交方收费，具体市场的版本、费用参数和最终净收份额需要逐一确认。新的低成本切入点因此仍是“完整支付约束＋真实成交成本核验”，不是先训练预测模型。[官方费用](https://docs.polymarket.com/trading/fees)、[具体市场参数](https://docs.polymarket.com/market-data/market-details)

作者原始代码/数据包仍未取得；本轮已经进一步查到正式出版商、共同作者和首作者机构入口。没有取得全部持仓、成交、退出和费用原件，不能宣布已经找到可继承的扣费盈利案例，也不能估计个人容量或财富路径。

## 2．一组完整交易在机制上如何闭合

下面是机制路径，不是已发生的个人成交，也没有调用交易接口：

```text
同一条件、同一可合并持仓系统的 YES 和 NO
            ↓ 实际足额取得、净余额配齐
         完整且等量的权利组合
            ↓ 适用合并路线、授权与链上确认
             取回抵押物
            ↓ 核对全部实际支出、费用与兑换
             才能认定净结果
```

这里的“合并”是把完整权利还原为抵押物；“解决后兑付”是按已确定结果领取单边支付。两者不能混为一谈。当前系统有CTF与Polymarket Protocol V2两类账本，文档给出不同路由；必须绑定具体市场版本和标识，不能把标题相似的两个市场、不同账本中的余额随意拼接。[官方持仓账本](https://docs.polymarket.com/concepts/positions-tokens)、[官方路由](https://docs.polymarket.com/trading/positions/manage)

官方说明已配对交易的链上结算具有原子性，即该笔结算整体成功或失败。但这**不证明两次分别提交的YES/NO订单也一定同时成交**。FOK表示一张订单全成或取消，不能仅凭该名称推导整套两腿交易全成或全退；本轮没有验证某个跨腿执行接口或私人程序。[订单生命周期](https://docs.polymarket.com/concepts/order-lifecycle)

因此，第一腿已经成交、第二腿没成交时，交易者仍然暴露于事件结果和退出价格。手续费较低的挂单也需要别人愿意成交，不能因为主动成交要付费，就把挂单成交概率设为100%。这两项为基于公开机制的推断，未测任何操作者的实际表现。

## 3．同一个教学价差，现行费用可能吃掉多少

**纯教学算术，不是真实报价、成交、回测、收益率或容量。** 额外假设如下：同一市场最终净取得100份YES和100份NO；每腿恰好一笔100份成交，价格0.46与0.50；费用另付；按官方费用页的Crypto示例参数rate=0.07、价格指数为1计算；pUSD与USDC在此只按1:1名义权利单位比较，未验证实际兑换及成本，不记任何返佣、奖励。

| 教学项目 | 条件算术结果 |
|---|---:|
| 两腿买入金额 | 96 |
| 完整组合对应抵押物 | 100 |
| 未扣费用差额 | 4 |
| YES腿公式费用 | 1.73880 |
| NO腿公式费用 | 1.75000 |
| 两腿公式费用合计 | 3.48880 |
| 其余成本前条件差额 | 0.51120 |

费用采用官方公开公式：份数×费率×价格×(1−价格)。上述数字只说明门槛：在这些假设下，其余相关成本超过0.51120，同一组合就不再留下正差额；它没有证明市场上存在这种机会。[官方费用公式与精度](https://docs.polymarket.com/trading/fees)

实际必须读取市场`feesEnabled`、费率、指数及收取方等参数，而非只凭“加密市场”标签。本轮没有读取任何具体市场实时报价、实际费率或原始扣款；若手续费从收到的份额扣取，或者发生拆分成交，必须重新核净得份额和逐笔舍入，不能直接套上表。具体扣取方式在本轮保持UNKNOWN。[市场费用字段](https://docs.polymarket.com/market-data/market-details)

官方费用页以USDC表述收费，当前持仓/抵押物文档使用pUSD，并说明其代表USDC权利和包装/解包路径。本轮未独立核储备、暂停状态或真实兑换，不能把100pUSD写成100美元已经到账。网络、失败、桥接、兑换或资金占用成本是否发生、由谁支付，均要原账确认；不得虚构额外费用，也不得缺失就填零。[官方抵押物说明](https://docs.polymarket.com/concepts/pusd)

## 5．你能复制什么，缺少时有什么后果

| 环节 | 个人目前能借鉴的部分 | 缺少关键条件的后果 |
|---|---|---|
| 权利关系 | 读公开规则，核同一条件与完整支付集合 | 把相似问题当等价权利，可能变成方向下注 |
| 成本核验 | 分开记录毛差额、实际收费与净得数量 | 看见正价差却实际亏损，或余额不够合并 |
| 执行与确认 | 区分挂单、匹配、链上确认、合并及兑换 | 把尚未闭合的组合记为利润 |
| 扩大规模 | 需要每腿可成交深度、机会寿命、竞争与资金周转证据 | 不能拿100份的算术乘到5000美元或百万美元 |

前两项可从免费公开资料开始，不需要大客户或大型算力。其余涉及实际数据、执行、资格与账户条件；本轮未核准为你可实施，更未执行。强模型不能替代相同权利、可成交数量或低费用。当前未证明个人持续净优势，Gerko财富1%的目标仍未达。

本研究样本不建议独立立项开发。后续只有能补上具体闭合组合及其原始成本、或明确作者发布包的证据，才会改变它的盈利判断；继续寻找更多宣传数字或反复搜索相同出版入口不增加证据。即使核到一笔正净额，也仍须另证跨时期表现、失败成本与容量。
