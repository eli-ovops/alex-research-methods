# BTC预测失败诊断：35倍误差从哪里来

日期：2026-10-17。范围：只读此前代码、数据、封存预测及自有权重；没有构造网络、进行前向计算、训练、调参、生成新预测、重解线性模型、回测或交易。原预测与`NOT_SUPPORTED_THIS_SETUP`判定未改。

**结论：可以确认这份LSTM在价格下移时持续预测偏高，且平方误差被少数较大的错误显著放大；没有发现足以解释35倍的评分、行错位或逆缩放错误。但现有文件不能区分未收敛、欠拟合、过拟合和价格分布变化的各自作用，所以不能把它写成“订单簿没有预测信息”或“LSTM本身没有优势”。另外，上轮漏列了岭回归的9条数值警告，线性对照的生成可靠性应降级待核。**

当前不值得把这份固定实现推进交易开发，也不宜在这三天已见结果上反复调参。值得保留的下一项研究问题是：这组已经训练好的权重，究竟有没有学会基本的价格跟随；现有记录尚不足以回答。本轮没有启动新的模型验证。

## 1. 35倍不是通常绝对误差也大35倍

本次误差为`(封存预测价−实际目标价)/最后已知价`，下表使用原来全部2,972行，不剔除日期或极端记录。

| 指标 | 挂单压力版LSTM | 不变价格基准 | 倍数 |
|---|---:|---:|---:|
| 均方误差MSE，误差平方后取平均 | 0.000111014671 | 0.000003176604 | **34.9476** |
| 均方根误差RMSE，将MSE开平方 | 105.36基点 | 17.82基点 | **5.9116** |
| 平均绝对误差MAE | 59.54基点 | 9.53基点 | **6.2484** |

1基点=0.01个百分点。这些是相对价格预测误差，不是交易收益率。平方运算放大大错误，35倍MSE对应约5.91倍RMSE；这解释了倍数的口径，但没有消除模型确实明显更差的事实。

加入I0挂单压力，仅使LSTM相对价格版改善0.914307%。这个比较发生在两个都明显输给简单基准的模型之间，不能据此认定获得了可用优势。

## 2. 误差集中在持续高估低价

| 部分UTC日期 | 时点数 | 占LSTM全部平方误差 | 平均有符号误差 |
|---|---:|---:|---:|
| 2021-04-17 | 1,215 | 0.47% | −1.40基点 |
| 2021-04-18 | 1,255 | **98.39%** | **+121.15基点** |
| 2021-04-19 | 502 | 1.13% | +21.04基点 |

正号表示预测偏高。4月18日1,255条中有1,162条预测高于实际；当日平均误差平方占当日MSE的56.74%。按数学恒等式，MSE=误差总体方差+平均误差的平方。这说明已保存输出存在明显的成片高估，不能把它描述成仅仅多了些正负对称噪声；它还不是训练原因的因果识别。

训练期目标中间价范围为55,430.325—64,858.995；测试期最低为52,430.65。**473条测试目标低于训练最低价，占全部测试15.92%，贡献了LSTM总平方误差的76.45%。**这473条的平均高估为208.22基点，而不变价格基准的平均误差仅为+1.71基点。

其余2,499条也完整保留，LSTM平均高估24.98基点。三个部分日期的LSTM均输给不变价格，不能通过删去4月18日把原结果重新宣布为成功。上述区间分组使用事后实际目标，只用于解释，不能作为交易时已知的筛选条件。

### 一条真实封存记录

目标时间：UTC 2021-04-18 03:37:06.377516，源行15,302。以下沿用原CSV的报价单位。

| 项目 | 价格 |
|---|---:|
| 输入中的最后已知中间价 | 52,473.05 |
| 挂单压力LSTM的封存预测 | **57,783.26** |
| 下一目标实际中间价 | **52,430.65** |
| LSTM的有符号价格误差 | **+5,352.61** |
| 不变价格的有符号价格误差 | **+42.40** |

按本次输入规则，模型已能看到52,473.05这一低价，却仍报出57,783.26。因此这条错误不只是“没有预见下一分钟突然下跌”；它在已知价格下移后仍明显报高。该行用于解释失败表现，35倍结论仍来自全部2,972行。

## 3. 哪些原因已能区分

| 问题 | 现有证据 | 判断 |
|---|---|---|
| 评分算错、MSE口径不同 | 原预测与实际逐行绑定；独立重算总体、逐日误差一致，模型与基准使用同一分母 | 没有发现该类错误，35倍是封存结果的真实算术关系 |
| 时间错一行、目标进入输入 | 代码使用i−30至i−1，目标为i；冻结索引、时间、实际与上一价格对应 | 没有发现该类适配错误 |
| 把测试期用于标准化，或逆变换用错均值/标准差 | 输入统计仅来自唯一训练输入行，标签统计仅来自训练标签；逆变换使用相同标签统计 | 没有发现该类错误；输入和标签各用自己的统计并非混用 |
| 跨缺口把30行误当30分钟 | 时间资格要求31个相邻快照全部连续60秒，71处异常间隔影响的窗口事前排除 | 未发现此类错误导致本次结果 |
| 根本没训练，或只训练一部分 | 每组10轮日志与Adam每个参数1,870步计数一致 | 支持确实执行训练，不证明训练已收敛 |

## 4. 不能强行归因的两个点

**第一，不能说输出层“被卡在55,000以上”。**本次只读自有封存参数，没有构造模型或进行前向计算。无投影LSTM的每个隐藏输出位于[−1,1]；给定固定线性头，可推导一个必要的输出范围。挂单压力版还原到价格后约为52,004.88—68,159.92，全部测试真值都在这个范围中。

这个范围是宽松的数学外界，不保证每个价格都能由真实输入达到，但不支持用它证明“硬下限排除了测试低价”。本批预测最低约55,681.59，说明实际映射未跟上下移；没有保存隐状态或门值，不能把“激活饱和”写成已证原因。[参数只读记录](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/evidence/BTC1min-failure-diagnosis-20261017/protocol/owned-head-parameter-read.json>)、[根独立原始存储核对](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/evidence/BTC1min-failure-diagnosis-20261017/root/independent-diagnostic-admission.json>)。

**第二，不能在缺少学习曲线时断言欠拟合或过拟合。**现有日志只有轮次完成，没有逐轮训练损失、验证损失，也没有最终训练集预测。有限损失、固定轮数和正常退出证明不了“已经学好”。当前无法区分训练不足、欠拟合、过拟合及优化路径影响。

【推断】直接学习绝对价格水平、短训练期、低价区间变化和非线性外推，都是值得优先怀疑的机制。训练目标是标准化价格水平MSE，评分却按上一价格归一化，两个目标的误差权重也不完全相同。这些属于设计局限的可能解释，不是已找到的代码错误，更不是已证明的唯一原因。

本次还不是原作者精确复现：原示例使用154列及Keras路径，本次为3通道、Torch显式初始化、严格时间筛选和匹配消融。结果不能用于宣布原作者所有方法、所有LSTM、Kronos或XTX的模型均无效。

## 5. 必须更正：岭回归的数值可靠性待核

原[运行stderr](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/evidence/BTC1min-fixed-evaluation-run-20261017/artifacts/resource-session-0003-fit_predict.stderr.txt>)存在9条RuntimeWarning，涉及矩阵乘中的除零、溢出和无效值，位置为339、340、342行：训练矩阵的乘积、右端项及测试预测矩阵乘。上轮报告漏列了这些警告，这是证据呈现遗漏，本次更正。

按代码执行顺序，这些线性计算发生在两组LSTM完成预测并保存权重之后，**没有证据把它作为LSTM35倍误差的原因**。日志也不足以确定具体涉及一个还是两个岭回归版本。

已保存的90个系数均有限且量级较小。基于原输入范围算出的理想数学矩阵元素上界约1.63×10⁸，远低于float64上限；这既不能证明警告无害，也不能认证实际后端中间计算正确。中间矩阵未保存，根因仍为UNKNOWN。本轮没有重新矩阵乘、解方程或生成预测去消除警告。

因此，原有线性预测文件的误差数值仍可如实报告，但不能继续把它当成“线性模型生成过程数值健康已确认”的证据，也不能据此充分否定线性方法。LSTM主对照失败的封存输出与算术结论保留。[日志与源码纠正记录](</Volumes/EXTERNAL/亚力克斯 /运行验证-20261015/evidence/BTC1min-failure-diagnosis-20261017/root/static-source-and-warning-review.json>)。

## 6. 值不值得继续

**不值得继续的是这份实现的交易开发、扩大算力，或围绕已见测试段刷参数。**本次没有可用价格预测优势，更没有扣费利润证据；算力费用并不是当前关键瓶颈。

**可以继续的只有范围有限的诊断研究，不能直接升级为赚钱项目。**若以后另行决定运行，唯一优先任务应是：仅补现有封存权重在原训练集上的一次前向输出，不重训、不重跑测试预测；对照训练期的最后已知价格基准，再与已封存测试误差比较，查看它是否连基本跟价都没学会。最终训练误差很大与训练误差很小、后续误差很大，会把排查方向分别指向可训练性/拟合问题和泛化/分布变化问题；仍不能单凭这一项认定唯一原因。这只是失效诊断，不是新增样本外验证；原方案没有独立验证集。

这项未来诊断无法补回已经没有保存的历史学习曲线，不应重新训练来伪造它。本轮未执行，也未要求追加运行许可。即使诊断找到可修正点，之后证明优势仍需新的固定方案和独立时期，不能继续把这2,972个已见时点当作未见测试，更不能把预测误差改善直接换算为盈利。
